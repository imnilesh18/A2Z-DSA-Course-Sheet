# 3536. Maximum Product of Two Digits

## 📝 Problem Statement

You are given a positive integer `n`. Return the maximum product of any two digits in `n`.

> **Note:** You may use the same digit twice if it appears more than once in `n`.

---

## 🚦 Constraints

* `10 <= n <= 10^9`

---

## 💡 Examples

| Example | Input | Output | Explanation |
| :--- | :--- | :--- | :--- |
| **1** | `n = 31` | `3` | The digits of `n` are `[3, 1]`. The possible products of any two digits are: `3 * 1 = 3`. The maximum product is `3`. |
| **2** | `n = 22` | `4` | The digits of `n` are `[2, 2]`. The possible products of any two digits are: `2 * 2 = 4`. The maximum product is `4`. |
| **3** | `n = 124` | `8` | The digits of `n` are `[1, 2, 4]`. The possible products of any two digits are: `1 * 2 = 2`, `1 * 4 = 4`, `2 * 4 = 8`. The maximum product is `8`. |

---

## 🛠️ Approach

### Brute-Force
The most straightforward way is to extract every digit of `n`, place them into an array or list, and then sort that list in ascending or descending order. The maximum product will simply be the multiplication of the two largest digits (the last two elements of the sorted array). 

### Optimized
Instead of allocating memory for an array and paying the overhead for sorting, we can track the top two largest digits in a single pass. We initialize two variables (`maxDigit` and `secondMaxDigit`) to zero. As we extract each digit from right to left using modulo `10`, we compare it against our tracked maximums and update them accordingly. This operates in constant space and linear time relative to the number of digits.

## 💻 Solution Code

### Brute-Force Solution (C++)

```cpp
// Intuition: The simplest way to find the maximum product of two digits is to extract all digits, sort them, and multiply the top two.
// Approach: Extract each digit using modulo arithmetic, store them in a vector, sort the vector in ascending order, and multiply the last two elements.
// Time Complexity: O(D log D), where D is the number of digits in n. Since D is at most 10, this is very fast.
// Space Complexity: O(D), to store the digits in a vector.
class Solution {
public:
    int maxProduct(int n) {
        vector<int> digits;
        
        // Extract all digits
        while (n > 0) {
            digits.push_back(n % 10);
            n /= 10;
        }
        
        // Sort digits in ascending order
        sort(digits.begin(), digits.end());
        
        // Multiply the two largest digits at the end
        int size = digits.size();
        return digits[size - 1] * digits[size - 2];
    }
};

/*
*
* Dry Run
* Input: n = 124
* Extracted digits: [4, 2, 1]
* Sorted vector: [1, 2, 4]
* Result: 4 * 2 = 8
*
*/
```

### Optimized Solution (C++)

```cpp
// Intuition: We only need the two largest digits, so we can find them in a single pass without arrays or sorting.
// Approach: Use two variables to keep track of the highest and second-highest digits seen so far while peeling off digits one by one.
// Time Complexity: O(D), where D is the number of digits in n (log10(n)).
// Space Complexity: O(1), as we only use two integer variables.
class Solution {
public:
    int maxProduct(int n) {
        int maxDigit = 0;
        int secondMaxDigit = 0;

        // Process each digit right to left
        while(n > 0) {
            int r = n % 10; // Extract the last digit
            
            // Current digit replaces max, old max becomes second max
            if(maxDigit < r) {
                secondMaxDigit = maxDigit;
                maxDigit = r;
            } 
            // Current digit is smaller than max but larger than second max
            else if(secondMaxDigit < r) {
                secondMaxDigit = r;
            }
            
            n /= 10; // Shift number to the right
        }

        // Return the product of the two largest digits
        return maxDigit * secondMaxDigit;
    }
};

/*
*
* Dry Run
* Input: n = 124
* Loop 1: r = 4. maxDigit = 4, secondMaxDigit = 0. n = 12
* Loop 2: r = 2. maxDigit = 4, secondMaxDigit = 2. n = 1
* Loop 3: r = 1. No updates. n = 0
* Return maxDigit (4) * secondMaxDigit (2) = 8
*
*/
```

## 📌 Notes
- Since the constraints state that `n <= 10^9`, the integer will comfortably fit within a standard 32-bit signed integer. 
- The maximum possible product for any two digits is `9 * 9 = 81`, which prevents any possibility of integer overflow upon multiplication.

## 🔑 Key Insights
- **Single Pass Efficiency:** Keeping a running tally of the "top 2" or "top N" items is a common optimization pattern that eliminates the need for `O(N log N)` sorting when `N` is small or when you only care about a few extreme values.
- **Handling Duplicates:** The `if / else if` logic perfectly handles duplicate digits. If `r` equals `maxDigit`, it falls through the first condition and can update `secondMaxDigit` if necessary (though in this specific logic structure, duplicate maximums won't re-trigger the second `else if` since it requires `secondMaxDigit < r`. Wait, actually, if `r == maxDigit`, it skips both `if` and `else if`. Wait! If `n = 22`, loop 1: `max = 2, sec = 0`. loop 2: `r = 2`. `maxDigit < r` is false. `secondMaxDigit < r` (0 < 2) is true! So `secondMaxDigit` becomes 2. The logic natively handles exact duplicates gracefully without strictly tracking equality).
