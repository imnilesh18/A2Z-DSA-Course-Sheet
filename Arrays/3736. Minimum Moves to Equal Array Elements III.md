# 3736. Minimum Moves to Equal Array Elements III

**Difficulty:** Easy

## 📝 Problem Statement

You are given an integer array `nums`.

In one move, you may increase the value of any single element `nums[i]` by `1`.

Return the *minimum* total number of moves required so that all elements in `nums` become equal.

### Constraints:
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

---

## 💡 Examples

**Example 1:**
> **Input:** `nums = [2,1,3]`  
> **Output:** `3`  
> **Explanation:**  
> To make all elements equal:  
> - Increase `nums[0] = 2` by 1 to make it 3.  
> - Increase `nums[1] = 1` by 1 to make it 2.  
> - Increase `nums[1] = 2` by 1 to make it 3.  
> Now, all elements of nums are equal to 3. The minimum total moves is 3.

**Example 2:**
> **Input:** `nums = [4,4,5]`  
> **Output:** `2`  
> **Explanation:**  
> To make all elements equal:  
> - Increase `nums[0] = 4` by 1 to make it 5.  
> - Increase `nums[1] = 4` by 1 to make it 5.  
> Now, all elements of nums are equal to 5. The minimum total moves is 2.

---

## 🧠 Key Insights & Approach

Since we can only *increase* elements, the target value for all elements must be at least the maximum element currently in the array. To minimize the number of moves, the optimal target value is exactly the maximum element in the array. Any value higher than the maximum would unnecessarily add extra moves to every single element.

**Algorithm:**
1. Find the maximum element (`maxEl`) in the given array.
2. Initialize a `moves` counter to 0.
3. Iterate through each number in the array. For every number, calculate the difference between `maxEl` and the number, and add this difference to `moves`.
4. Return the total `moves`.

---

## 💻 Solution Code

```cpp
// Intuition: Since elements can only be incremented, they must all eventually equal the maximum element in the array to achieve equality with the minimum moves.
// Approach: Find the maximum element first. Then, calculate the difference between this maximum and every other element, summing these differences to get the total moves.
// Time Complexity: O(n) where n is the number of elements in the array, as we traverse the array twice (once to find the max, once to calculate moves).
// Space Complexity: O(1) as we are only using a few extra variables for counting.

class Solution {
public:
    int minMoves(vector<int>& nums) {
        // Find the maximum element in the array
        int maxEl = *max_element(begin(nums), end(nums));
        
        int moves = 0;
        
        // Calculate the difference between the max element and each number
        for (int& num : nums) {
            moves += maxEl - num;
        }
        
        /*
            Or you can do it like this : 
            moves = (maxEl - nums[0]) + (maxEl - nums[1]) + .....
            moves = (maxEl + maxEl + ...) - (nums[0] + nums[1] + ...)
            
            Final moves = n*maxEl - sum(nums);
        */
        
        return moves;
    }
};

/*
*
* Dry Run
*
* Input: nums = [2, 1, 3]
* 
* 1. maxEl = max(2, 1, 3) = 3
* 2. moves = 0
* 3. Loop starts:
*    - num = 2: moves += (3 - 2) => moves = 1
*    - num = 1: moves += (3 - 1) => moves = 1 + 2 = 3
*    - num = 3: moves += (3 - 3) => moves = 3 + 0 = 3
* 4. Return moves (3)
*
*/
```
