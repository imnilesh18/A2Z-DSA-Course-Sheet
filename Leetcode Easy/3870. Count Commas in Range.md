## 📜 Problem Statement

You are given an integer `n`. Return the total number of commas used when writing all integers from `[1, n]` (inclusive) in standard number formatting.

**In standard formatting:**
- A comma is inserted after every three digits from the right.
- Numbers with fewer than 4 digits contain no commas.

---

## 🚫 Constraints

- `1 <= n <= 10^5`

---

## 💡 Examples

| Example | Input | Output | Explanation |
| :--- | :--- | :--- | :--- |
| **Example 1** | `n = 1002` | `3` | The numbers "1,000", "1,001", and "1,002" each contain one comma, giving a total of 3. |
| **Example 2** | `n = 998` | `0` | All numbers from 1 to 998 have fewer than four digits. Therefore, no commas are used. |

## 🧠 Approach

<details>
<summary><b>Click to reveal the detailed walkthrough</b></summary>

To solve this problem, we need to understand the distribution of commas in standard number formatting based on the constraints provided.

1. **Understand Comma Placement:**
   - Any number from `1` to `999` has less than 4 digits. Thus, they require **0 commas**.
   - Numbers from `1,000` to `999,999` require exactly **1 comma**.
   
2. **Analyze Constraints:**
   - The problem states that `n` can go up to a maximum of `10^5` (i.e., `100,000`).
   - Because `100,000` is the absolute maximum value we will process, we will *never* encounter a number that requires more than 1 comma. 
   - Therefore, every number from `1000` to `n` (if `n >= 1000`) will contribute exactly **one comma** to our total count.

3. **Formulating the Brute-Force Solution:**
   - We can run a simple `for` loop starting from `1` up to `n`. 
   - Every time we encounter a number strictly greater than `999`, we increment our comma count by 1. 

4. **Formulating the Optimized Solution:**
   - Since we know that every number from `1000` to `n` contains exactly one comma, the total number of commas is simply the count of integers in the range `[1000, n]`.
   - The formula for the count of numbers in an inclusive range `[a, b]` is `b - a + 1`. 
   - Substituting our values, we get: `n - 1000 + 1`, which simplifies to `n - 999`.
   - If `n` is less than `1000`, this formula evaluates to a negative number. To handle this gracefully without conditionals, we can just return the maximum between `n - 999` and `0` using `max(n - 999, 0)`.

</details>

## 💻 Solution Code

### Brute-Force Solution (C++)

```cpp
// Intuition: Numbers less than 1000 have no commas. Given the constraint max n = 10^5, numbers >= 1000 will only ever have exactly 1 comma.
// Approach: Iterate through all numbers from 1 to n. Check if the number is greater than 999, and if so, add 1 to the result counter.
// Time Complexity: O(n) - We loop through n numbers to check their values.
// Space Complexity: O(1) - Constant extra space used for the counter variable.
class Solution {
public:
    int countCommas(int n) {
        int result = 0; // Initialize our total comma counter
        
        for (int num = 1; num <= n; num++) { // Loop sequentially through the range
            if (num > 999) { // Any number >= 1000 adds exactly 1 comma
                result += 1; // Increment total comma count
            }
        }

        return result;
    }
};

/*
*
* Dry Run
* n = 1002
* num = 1 to 999 check is false result remains 0
* num = 1000 check is true result becomes 1
* num = 1001 check is true result becomes 2
* num = 1002 check is true result becomes 3
* Loop ends returning result 3
*
*/
```

### Optimized Solution (C++)

```cpp
// Intuition: Since every valid number >= 1000 contributes exactly 1 comma, the answer is just the total count of numbers in the range [1000, n].
// Approach: Calculate the length of the range [1000, n] mathematically using (n - 1000) + 1, simplifying to n - 999. Use max() to avoid negative results for n < 1000.
// Time Complexity: O(1) - Only a single mathematical calculation is performed.
// Space Complexity: O(1) - No auxiliary data structures are used.
class Solution {
public:
    int countCommas(int n) {
        // Return the count of numbers in [1000, n], floored at 0
        return max(n - 999, 0);
    }
};

/*
*
* Dry Run
* n = 1002
* Calculate n - 999 which is 1002 - 999 = 3
* Evaluate max(3, 0) which is 3
* Return 3
*
*/
```

## 📝 Notes & Key Insights
* **Mathematical Ranges:** Whenever dealing with counting sequentially occurring identical traits, finding the formula for the count `(End - Start + 1)` is always more efficient than loop-based simulation.
* **Constraint Awareness:** This problem relies heavily on checking the maximum possible input. If `n` reached `10^9`, we would have needed a progressively compounding logic to account for numbers with 2 and 3 commas.
* **Graceful Edge-Case Handling:** The `max(0, val)` technique is an incredibly elegant, single-line way to prevent negative integer logic without writing bulky `if/else` statements.
