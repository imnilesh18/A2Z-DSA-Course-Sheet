# 2409. Count Days Spent Together

**Problem Link:** [LeetCode - Count Days Spent Together](https://leetcode.com/problems/count-days-spent-together/description/)
**Difficulty:** Easy
**Tags:** Math, String

---

## 📝 Problem Statement

Alice and Bob are traveling to Rome for separate business meetings.

You are given 4 strings `arriveAlice`, `leaveAlice`, `arriveBob`, and `leaveBob`. Alice will be in the city from the dates `arriveAlice` to `leaveAlice` (inclusive), while Bob will be in the city from the dates `arriveBob` to `leaveBob` (inclusive). Each will be a 5-character string in the format `"MM-DD"`, corresponding to the month and day of the date.

Return the total number of days that Alice and Bob are in Rome together.

You can assume that all dates occur in the same calendar year, which is not a leap year. Note that the number of days per month can be represented as: `[31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]`.

---

## 🚫 Constraints

- All dates are provided in the format `"MM-DD"`.
- Alice and Bob's arrival dates are earlier than or equal to their leaving dates.
- The given dates are valid dates of a non-leap year.

---

## 💡 Examples

| Example | Input | Output | Explanation |
| :--- | :--- | :--- | :--- |
| **1** | `arriveAlice = "08-15"`, `leaveAlice = "08-18"`<br>`arriveBob = "08-16"`, `leaveBob = "08-19"` | `3` | Alice is in Rome from Aug 15 to Aug 18. Bob is in Rome from Aug 16 to Aug 19. They overlap on Aug 16, 17, and 18. |
| **2** | `arriveAlice = "10-01"`, `leaveAlice = "10-31"`<br>`arriveBob = "11-01"`, `leaveBob = "12-31"` | `0` | There is no day when Alice and Bob are in Rome together. |

## 🧠 Approach

Every day in a non-leap year can be mapped to a specific "Day of the Year" ranging from 1 to 365. Instead of doing complex date arithmetic, we can convert all four given dates ("MM-DD") into integers representing their specific day in the year. 

**Step-by-Step Conversion:**
1. Maintain an array of the number of days in each month.
2. Build a cumulative (prefix sum) array from this to quickly find how many days have passed before the start of any given month.
3. For a given date (e.g., `08-15`), the Day of the Year is the sum of all days in the preceding months (January to July) plus the day itself (15).
4. After converting Alice's and Bob's arrival and departure dates into simple integer points on a 1D number line, calculating the overlap becomes straightforward.
5. The start of their overlap is the maximum of their arrival days: `max(arriveAlice, arriveBob)`.
6. The end of their overlap is the minimum of their departure days: `min(leaveAlice, leaveBob)`.
7. The total days spent together is `end - start + 1`. If this value is negative, it means their intervals do not overlap at all, so we return `0`.

## 💻 Optimized Solution (C++)

```cpp
// Intuition: The problem asks for the overlapping days between two date ranges in a non-leap year. By converting every date ("MM-DD") to its corresponding "day of the year" (1 to 365), we reduce the problem to finding the intersection of two 1D line segments.
// Approach: 
// 1. Create a prefix sum array of days in each month to quickly find how many days have passed before a given month.
// 2. Extract the month and day from the string, convert to integers, and calculate the exact day of the year.
// 3. Find the day of the year for all four given dates (Alice's and Bob's arrival and departure).
// 4. Calculate the overlap: start is the maximum of their arrival days, end is the minimum of their departure days.
// 5. Overlap length is (end - start + 1). If start > end, they don't overlap, return 0.
// Time Complexity: O(1) because the date formats and month arrays are of constant size.
// Space Complexity: O(1) since we only use a fixed-size array of 13 elements.

class Solution {
public:
    // Helper function to calculate the Nth day of the year for a given "MM-DD"
    int findDayOfYear(const string& day, const vector<int>& cumMonthDays) {
        // Extract month and date parts using substring and convert to integer
        int month = stoi(day.substr(0, 2));
        int date  = stoi(day.substr(3));
        
        // Return cumulative days of previous months + current date
        return cumMonthDays[month - 1] + date;
    }

    int countDaysTogether(string arriveAlice, string leaveAlice,
                          string arriveBob, string leaveBob) {
        // Number of days in each month for a non-leap year
        vector<int> monthDays = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

        // Array to store cumulative days up to the previous month
        vector<int> cumMonthDays(13, 0);
        cumMonthDays[1] = 31; // January
        
        // Build the prefix sum array for the months
        for(int i = 1; i <= 12; i++) {
            cumMonthDays[i] = cumMonthDays[i-1] + monthDays[i-1];
        }

        // Convert all dates to their respective "day of the year"
        int arriveAliceDay  = findDayOfYear(arriveAlice, cumMonthDays);
        int leaveAliceDay   = findDayOfYear(leaveAlice, cumMonthDays);
        int arriveBobDay    = findDayOfYear(arriveBob, cumMonthDays);
        int leaveBobDay     = findDayOfYear(leaveBob, cumMonthDays);

        // Calculate the overlapping days
        // Start of overlap is the max of their arrival dates
        // End of overlap is the min of their leaving dates
        int overLapDays = min(leaveAliceDay, leaveBobDay) - max(arriveAliceDay, arriveBobDay) + 1;

        // If overlap is negative, they never met, so return 0
        return overLapDays < 0 ? 0 : overLapDays;
    }
};

/*
*
* Dry Run
* 
* Input: arriveAlice = "08-15", leaveAlice = "08-18", arriveBob = "08-16", leaveBob = "08-19"
* 
* 1. cumMonthDays array is built: [0, 31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334, 365]
* 
* 2. Find day for arriveAlice ("08-15"): 
*    month = 8, date = 15. Day = cumMonthDays[7] + 15 = 212 + 15 = 227
* 
* 3. Find day for leaveAlice ("08-18"): 
*    month = 8, date = 18. Day = cumMonthDays[7] + 18 = 212 + 18 = 230
* 
* 4. Find day for arriveBob ("08-16"): 
*    month = 8, date = 16. Day = cumMonthDays[7] + 16 = 212 + 16 = 228
* 
* 5. Find day for leaveBob ("08-19"): 
*    month = 8, date = 19. Day = cumMonthDays[7] + 19 = 212 + 19 = 231
* 
* 6. Calculate overlap:
*    start = max(227, 228) = 228
*    end = min(230, 231) = 230
*    overLapDays = 230 - 228 + 1 = 3
* 
* 7. overLapDays is positive, so return 3.
*
*/
```

## 📌 Notes
- We use a cumulative array size of 13 to utilize 1-based indexing for the months (i.e., `cumMonthDays[1]` refers to January).
- Always consider the edge case where the intervals do not overlap. The formula `end - start + 1` will yield a zero or negative number, which needs to be handled cleanly (e.g., using a ternary operator returning `0`).

---

## 🔑 Key Insights
- **Interval Overlap Formula:** The core concept of finding the intersection of two segments `[A, B]` and `[C, D]` using `[max(A, C), min(B, D)]` is widely applicable in scheduling, meeting rooms, and calendar problems.
- **Prefix Sums for Dates:** Converting dates into a linear scale using a prefix sum array of month lengths prevents the need for messy month-by-month traversal loops.
