# 1021. Remove Outermost Parentheses

**Problem Link:** [LeetCode 1021](https://leetcode.com/problems/remove-outermost-parentheses/description/)   
**Problem Name:** 1021. Remove Outermost Parentheses   
**Difficulty:** Easy   
**Tags:** `String`, `Stack`, `Bracket Sequences`

## 📝 Problem Statement

A valid parentheses string is either empty `""`, `"(" + A + ")"`, or `A + B`, where `A` and `B` are valid parentheses strings, and `+` represents string concatenation . 

A valid parentheses string `s` is primitive if it is nonempty, and there does not exist a way to split it into `s = A + B`, with `A` and `B` nonempty valid parentheses strings . 

Given a valid parentheses string `s`, consider its primitive decomposition: `s = P1 + P2 + ... + Pk`, where `Pi` are primitive valid parentheses strings . Return `s` after removing the outermost parentheses of every primitive string in the primitive decomposition of `s` .

## 🚀 Constraints

- `1 <= s.length <= 10^5` 
- `s[i]` is either `'('` or `')'` 
- `s` is a valid parentheses string 

## 💡 Examples

| Example | Input | Output | Explanation |
| :--- | :--- | :--- | :--- |
| **1** | `s = "(()())(())"`  | `"()()()"`  | The input string is `"(()())(())"`, with primitive decomposition `"(()())" + "(())"` . After removing outer parentheses of each part, this is `"()()" + "()" = "()()()"` . |
| **2** | `s = "(()())(())(()(()))"`  | `"()()()()(())"`  | The input string is `"(()())(())(()(()))"`, with primitive decomposition `"(()())" + "(())" + "(()(()))"` . After removing outer parentheses, this is `"()()" + "()" + "()(())" = "()()()()(())"` . |
| **3** | `s = "()()"`  | `""`  | The input string is `"()()"`, with primitive decomposition `"()" + "()"` . After removing outer parentheses, this is `"" + "" = ""` . |

## 🧠 Approach

<details>
<summary><b>Click to reveal the detailed walkthrough</b></summary>

We can determine the opening and closing of a primitive string using a simple `count` variable . 
- We initialize `count` to `0` .
- When we encounter an opening bracket `'('`, we check if `count != 0` . If it is not zero, it means this bracket is part of the inner string (not the outermost parenthesis), so we append it to our result . Then, we increment `count` by `1` .
- When we encounter a closing bracket `')'`, we first decrement `count` by `1` . If `count != 0` after decrementing, it means we have not yet reached the outermost closing bracket, so we append this bracket to our result .
- When `count` reaches `0`, it indicates we have found the outermost closing bracket of a primitive string, which we deliberately ignore and do not add to the result . 

</details>

## 💻 Solution Code (Optimized)

```cpp
// Intuition: A primitive string can be identified by tracking the balance of parentheses. The outermost brackets correspond to the transition from balance 0 to 1, and back to 0. We want to skip exactly these transitions.
// Approach: Iterate through the string while maintaining a `count` of open brackets. For an open bracket, if `count` > 0, it's an inner bracket; add it to the result and increment `count`. For a close bracket, decrement `count` first; if `count` > 0, it's an inner bracket, so add it to the result.
// Time Complexity: O(n) where n is the length of the string, as we iterate through the string exactly once.
// Space Complexity: O(1) auxiliary space (ignoring the space required for the output string).

class Solution {
public:
    string removeOuterParentheses(string s) {
        int count = 0;
        string result = "";

        for(char &ch : s) {
            if(ch == '(') {
                // If count is not 0, it's an inner open bracket
                if(count != 0) result.push_back(ch);
                
                // Increase bracket depth
                count++;
            } else {
                // Decrease bracket depth
                count--;
                
                // If count is not 0, it's an inner close bracket
                if(count != 0) result.push_back(ch);
            }
        }

        return result;
    }
};

/*
*
* Dry Run
*
* Input: s = "(()())(())"
* Init: count = 0, result = ""
*
* Char '(': count = 0 (Outer). count++ -> 1. result = ""
* Char '(': count = 1 (Inner). result = "(". count++ -> 2.
* Char ')': count-- -> 1. count = 1 (Inner). result = "()".
* Char '(': count = 1 (Inner). result = "()(". count++ -> 2.
* Char ')': count-- -> 1. count = 1 (Inner). result = "()()".
* Char ')': count-- -> 0. count = 0 (Outer). result = "()()".
* Char '(': count = 0 (Outer). count++ -> 1. result = "()()".
* Char '(': count = 1 (Inner). result = "()()(". count++ -> 2.
* Char ')': count-- -> 1. count = 1 (Inner). result = "()()()".
* Char ')': count-- -> 0. count = 0 (Outer). result = "()()()".
* 
* Final Output: "()()()"
*
*/
```
