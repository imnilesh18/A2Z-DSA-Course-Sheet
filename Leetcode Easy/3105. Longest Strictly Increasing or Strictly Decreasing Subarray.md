# 3105. Longest Strictly Increasing or Strictly Decreasing Subarray

**Problem Link:** [LeetCode - Longest Strictly Increasing or Strictly Decreasing Subarray](https://leetcode.com/problems/longest-strictly-increasing-or-strictly-decreasing-subarray)
**Difficulty:** Easy
**Tags:** Array

## 📝 Problem Statement

You are given an array of integers `nums`. Return the length of the longest subarray of `nums` which is either strictly increasing or strictly decreasing.

### Constraints:
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 50`

---

## 💡 Examples

| Example | Input | Output | Explanation |
| :--- | :--- | :--- | :--- |
| **1** | `nums = [1,4,3,3,2]` | `2` | The strictly increasing subarrays are `[1]`, `[2]`, `[3]`, `[3]`, `[4]`, and `[1,4]`. The strictly decreasing subarrays are `[1]`, `[2]`, `[3]`, `[3]`, `[4]`, `[3,2]`, and `[4,3]`. The longest of these has length 2. |
| **2** | `nums = [3,3,3,3]` | `1` | All strictly increasing and decreasing subarrays are of length 1 (just the individual elements). |
| **3** | `nums = [3,2,1]` | `3` | The strictly decreasing subarrays include `[3,2,1]`, which has a length of 3. |

---

## 🧠 Approach & Key Insights

### Brute Force Approach
The most straightforward method is to evaluate every possible starting point in the array. For each element at index `i`, we can check how far the sequence strictly increases and how far it strictly decreases by iterating forward with a second pointer `j`. We then update our global maximum length. While this ensures we don't miss any sequences, it performs redundant checks, leading to an $O(n^2)$ time complexity.

### Optimized Approach
Notice that when a sequence breaks (e.g., stops increasing), the next potential sequence starts right at that break point. We don't need to go back and restart our checks. We can maintain two counters: `increasing` and `decreasing`, both initialized to 1 (since a single element is technically a sequence of length 1). 
- As we iterate through the array once:
  - If the current element is greater than the previous, we extend the `increasing` sequence and reset the `decreasing` sequence to 1.
  - If the current element is smaller than the previous, we extend the `decreasing` sequence and reset the `increasing` sequence to 1.
  - If they are equal, both sequences break, and we reset both counters to 1.
- We continuously update our `result` with the maximum value of these counters. This brings the time complexity down to $O(n)$.

## 💻 Solution Code

### Brute Force Solution
```cpp
// Intuition: The simplest way is to check every possible subarray starting from each index to see how far it strictly increases or decreases.
// Approach: Iterate through the array with a starting index `i`. For each `i`, use another loop `j` to count the length of the increasing sequence, then do the same for the decreasing sequence. Keep track of the global maximum.
// Time Complexity: O(n^2) because for each element, we potentially scan the rest of the array.
// Space Complexity: O(1) as we only use a few integer variables for counting.

class Solution {
public:
    int longestMonotonicSubarray(vector<int>& nums) {
        int n = nums.size();
        int result = 0;
        
        for(int i = 0; i < n; i++) {
            int increasing = 1; // Base length is 1 for the element itself
            int j = i + 1;
            
            // Check how far it strictly increases
            while(j < n && nums[j] > nums[j-1]) {
                increasing++;
                j++;
            }

            int decreasing = 1; // Base length is 1 for the element itself
            j = i + 1;

            // Check how far it strictly decreases
            while(j < n && nums[j] < nums[j-1]) {
                decreasing++;
                j++;
            }

            // Update the global maximum length found so far
            result = max({result, increasing, decreasing});
        }

        return result;
    }
};

/*
*
* Dry Run
* nums = [1, 4, 3, 3, 2]
* 
* i = 0 (nums[0] = 1):
*   increasing: j=1 (4 > 1) -> 2. j=2 (3 < 4) -> stops. (increasing = 2)
*   decreasing: j=1 (4 > 1) -> stops. (decreasing = 1)
*   result = max(0, 2, 1) = 2
*
* i = 1 (nums[1] = 4):
*   increasing: j=2 (3 < 4) -> stops. (increasing = 1)
*   decreasing: j=2 (3 < 4) -> 2. j=3 (3 == 3) -> stops. (decreasing = 2)
*   result = max(2, 1, 2) = 2
*
* i = 2 (nums[2] = 3):
*   increasing: j=3 (3 == 3) -> stops. (increasing = 1)
*   decreasing: j=3 (3 == 3) -> stops. (decreasing = 1)
*   result = max(2, 1, 1) = 2
*
* ... and so on. Final result is 2.
*
*/
```

### Optimized Solution
```cpp
// Intuition: Instead of recounting from each index, we can just keep track of the current increasing and decreasing sequence lengths as we iterate through the array once.
// Approach: Iterate from the second element. If it's greater than the previous, increment the `increasing` counter and reset `decreasing` to 1. If it's smaller, increment `decreasing` and reset `increasing` to 1. If they are equal, reset both counters to 1. Track the maximum of these counters at each step.
// Time Complexity: O(n) since we only pass through the array exactly once.
// Space Complexity: O(1) because we only need variables to store current streak lengths and the maximum result.

class Solution {
public:
    int longestMonotonicSubarray(vector<int>& nums) {
        int n = nums.size();
        
        int result = 1;
        int increasing = 1;
        int decreasing = 1;
        
        for(int i = 1; i < n; i++) {
            if(nums[i] > nums[i-1]) {
                // Sequence is strictly increasing
                increasing++;
                decreasing = 1; // Break the decreasing streak
                result = max(result, increasing);
            } else if(nums[i] < nums[i-1]) {
                // Sequence is strictly decreasing
                decreasing++;
                increasing = 1; // Break the increasing streak
                result = max(result, decreasing);
            } else {
                // Elements are equal, both sequences break
                increasing = 1;
                decreasing = 1;
            }
        }

        return result;
    }
};

/*
*
* Dry Run
* nums = [1, 4, 3, 3, 2]
* Initial state: result = 1, inc = 1, dec = 1
*
* i = 1 (nums[1] = 4, nums[0] = 1):
*   4 > 1 -> inc = 2, dec = 1
*   result = max(1, 2) = 2
*
* i = 2 (nums[2] = 3, nums[1] = 4):
*   3 < 4 -> dec = 2, inc = 1
*   result = max(2, 2) = 2
*
* i = 3 (nums[3] = 3, nums[2] = 3):
*   3 == 3 -> inc = 1, dec = 1
*   result remains 2
*
* i = 4 (nums[4] = 2, nums[3] = 3):
*   2 < 3 -> dec = 2, inc = 1
*   result = max(2, 2) = 2
*
* Final result is 2.
*
*/
```
