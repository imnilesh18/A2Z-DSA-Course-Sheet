## 📝 Problem Statement

You are given an integer array `nums`. Two players are playing a game with this array: player 1 and player 2.

Player 1 and player 2 take turns, with player 1 starting first. Both players start the game with a score of `0`. At each turn, the player takes one of the numbers from either end of the array (i.e., `nums[0]` or `nums[nums.length - 1]`) which reduces the size of the array by `1`. The player adds the chosen number to their score. The game ends when there are no more elements in the array.

Return `true` if Player 1 can win the game. If the scores of both players are equal, then player 1 is still the winner, and you should also return `true`. You may assume that both players are playing optimally.

## 🛑 Constraints

* `1 <= nums.length <= 20`
* `0 <= nums[i] <= 10^7`

## 💡 Examples

| Example | Input | Output | Explanation |
| :--- | :--- | :--- | :--- |
| **1** | `nums = [1,5,2]` | `false` | Initially, player 1 can choose between 1 and 2. If he chooses 2 (or 1), then player 2 can choose from 1 (or 2) and 5. If player 2 chooses 5, then player 1 will be left with 1 (or 2). So, final score of player 1 is 1 + 2 = 3, and player 2 is 5. Hence, player 1 will never be the winner and you need to return false. |
| **2** | `nums = [1,5,233,7]` | `true` | Player 1 first chooses 1. Then player 2 has to choose between 5 and 7. No matter which number player 2 chooses, player 1 can choose 233. Finally, player 1 has more score (234) than player 2 (12), so you need to return True representing player1 can win. |

## 🧠 Approach & Key Insights

This is a classic **Game Theory** problem that relies on the **Optimal Game Strategy** (Minimax Algorithm). Since both players play optimally, we must anticipate the worst-case scenario from our opponent while trying to maximize our own score. 

The core rules of optimal game strategy are:
1. **When it is your turn:** Do your best. Choose the option that yields the maximum possible score for you.
2. **When it is your opponent's turn:** Expect the worst. Since the opponent is also playing optimally, whatever move they make will minimize the score available to you in the next turn.

We can solve this using two similar recursive approaches with Memoization (Top-Down Dynamic Programming):
* **Approach 1 (Max Score Strategy):** Calculate the absolute maximum score Player 1 can secure. If Player 1 picks the left element, the opponent will forcefully leave Player 1 with the minimum of the next two possible future states. We sum all elements and check if Player 1's score is at least half of the total.
* **Approach 2 (Score Difference Strategy):** Instead of calculating the total score, we calculate the *difference* in scores. Whenever a player picks a number, their effective score advantage is that number *minus* whatever maximum advantage the opponent can get from the remaining array. Player 1 wins if this final difference is $\ge 0$.

## 💻 Solution Code

### Brute-force / Optimized Solution (Max Score Strategy)

```cpp
// Intuition: In an optimal game, a player will always try to maximize their score while the opponent will make choices that minimize the first player's future gains. We can simulate this by taking the max of our choices and the min of the future states left by the opponent.
// Approach: We use a recursive function `solve(l, r)` that returns the max score a player can get from the subarray `nums[l...r]`. When a player picks `nums[l]`, the opponent will pick either `l+1` or `r` in a way that minimizes the current player's next turn. Thus, picking left yields `nums[l] + min(solve(l+2, r), solve(l+1, r-1))`. We memoize these states to optimize overlapping subproblems.
// Time Complexity: O(N^2) where N is the length of the array, because there are N*N possible states for l and r, and each state is computed only once.
// Space Complexity: O(N^2) to store the memoization table `t`, plus O(N) for the recursive call stack depth.

class Solution {
public:
    int n;
    int t[23][23]; // Memoization table to store max score for subarray ranges
    
    int solve(vector<int>& nums, int l, int r) {
        // Base case: No elements left
        if(l > r)
            return 0;
        
        // Base case: Only one element left, player must take it
        if(l == r)
            return nums[l];
        
        // Return precomputed result if state has been visited
        if(t[l][r] != -1)
            return t[l][r];
        
        // Player chooses left end, opponent optimally minimizes our next turn
        int take_left  = nums[l] + min(solve(nums, l+2, r), solve(nums, l+1, r-1));
        
        // Player chooses right end, opponent optimally minimizes our next turn
        int take_right = nums[r] + min(solve(nums, l, r-2), solve(nums, l+1, r-1));
        
        // Store and return the best choice for the current player
        return t[l][r] = max(take_left, take_right);
    }
    
    bool predictTheWinner(vector<int>& nums) {
        memset(t, -1, sizeof(t));
        n = nums.size();
        
        // Calculate total sum of the array
        int total = accumulate(begin(nums), end(nums), 0);
        
        // Get Player 1's maximum guaranteed score
        int player1 = solve(nums, 0, n-1);
        
        // Player 2 gets the rest
        int player2 = total - player1;
        
        // Player 1 wins if they have at least half the points
        return player1 >= player2;
    }
};

/*
*
* Dry Run
*
* Input: nums = [1, 5, 2]
* Total score available is 8.
* solve(0, 2) is called for Player 1.
* Player 1 can take left (1) or right (2).
* If taking left (1), the remaining array is [5, 2]. The opponent plays optimally and takes 5, leaving Player 1 with 2. Player 1 gets 1 + 2 = 3.
* If taking right (2), the remaining array is [1, 5]. The opponent plays optimally and takes 5, leaving Player 1 with 1. Player 1 gets 2 + 1 = 3.
* The max score Player 1 can guarantee is 3.
* Player 2 gets total - 3 = 8 - 3 = 5.
* Player 1's score (3) is not >= Player 2's score (5), so the function returns false.
*
*/
```

### Optimized Solution (Score Difference Strategy)

```cpp
// Intuition: Instead of calculating absolute scores for both players, we can just calculate the relative score difference. If Player 1 can secure a difference >= 0, they win.
// Approach: The function `maxDiff(l, r)` computes the maximum score difference the current player can achieve over the other player from the subarray `nums[l...r]`. If the current player picks `nums[l]`, their net advantage is `nums[l] - maxDiff(l+1, r)` because the next turn belongs to the opponent who will maximize their own difference. We take the max of picking the left or right element.
// Time Complexity: O(N^2) where N is the array length. We evaluate each subarray state once and cache it.
// Space Complexity: O(N^2) for the 2D DP cache and O(N) auxiliary stack space for recursion.

class Solution {
public:
    int n;
    int t[23][23]; // DP table to store the max difference for a subarray
    
    // Returns the max difference in score (Current Player - Opponent)
    int maxDiff(vector<int>& nums, int l, int r) {
        
        // Base case: Only one element, current player takes it and gains that much difference
        if(l == r)
            return nums[l];
        
        // Return precalculated difference to save time
        if(t[l][r] != -1)
            return t[l][r];
        
        // Difference if we pick left: our element minus the best difference opponent can make
        int take_left  = nums[l] - maxDiff(nums, l+1, r);
        
        // Difference if we pick right: our element minus the best difference opponent can make
        int take_right = nums[r] - maxDiff(nums, l, r-1);
        
        // We play optimally, so we choose the move that gives the maximum difference
        return t[l][r] = max(take_left, take_right);
    }
    
    bool predictTheWinner(vector<int>& nums) {
        n = nums.size();
        memset(t, -1, sizeof(t));
        
        // If the max difference Player 1 can achieve is >= 0, they win or tie
        return maxDiff(nums, 0, n-1) >= 0;
    }
};

/*
*
* Dry Run
*
* Input: nums = [1, 5, 233, 7]
* maxDiff(0, 3) evaluates picking left (1) or right (7).
* If Player 1 picks 1, Player 2 is faced with [5, 233, 7]. Player 2 will pick 7 to expose 233 to themselves, but Player 1 anticipates this recursively. 
* By picking 1, Player 1 forces Player 2 into a state where Player 2 has to choose between 5 and 7, and no matter what Player 2 picks, Player 1 gets 233.
* The recursive calls subtract the opponent's best outcome from the current player's choice. 
* The difference bubbles up, ultimately resulting in a positive net score difference for Player 1 (234 vs 12).
* Since maxDiff >= 0, the function returns true.
*
*/
```
