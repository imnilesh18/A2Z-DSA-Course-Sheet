# 2267. Check if There Is a Valid Parentheses String Path

**Problem Link:** [Check if There Is a Valid Parentheses String Path](https://leetcode.com/problems/check-if-there-is-a-valid-parentheses-string-path/description/)
**Difficulty:** Hard
**Tags:** `Array`, `Dynamic Programming`, `Matrix`, `Bracket Sequences`

---

## 📖 Problem Statement

A parentheses string is a non-empty string consisting only of `'('` and `')'`. It is valid if any of the following conditions is true:
- It is `()`.
- It can be written as `AB` (`A` concatenated with `B`), where `A` and `B` are valid parentheses strings.
- It can be written as `(A)`, where `A` is a valid parentheses string.

You are given an `m x n` matrix of parentheses `grid`. A valid parentheses string path in the grid is a path satisfying all of the following conditions:
1. The path starts from the upper left cell `(0, 0)`.
2. The path ends at the bottom-right cell `(m - 1, n - 1)`.
3. The path only ever moves **down** or **right**.
4. The resulting parentheses string formed by the path is **valid**.

Return `true` if there exists a valid parentheses string path in the grid. Otherwise, return `false`.

---

## 🚦 Constraints

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 100`
- `grid[i][j]` is either `'('` or `')'`.

## 🧠 Approach

### Core Intuition
To form a valid parentheses string, the string must be perfectly balanced. We can verify this balance dynamically by keeping an `openCount`. We add `1` for every `'('` and subtract `1` for every `')'`. 
For a path to be valid:
1. The `openCount` must **never drop below 0** at any point.
2. The `openCount` must be **exactly 0** when reaching the final cell `(m-1, n-1)`.

### Step-by-Step Implementation

1. **Early Rejections (Pruning):**
   - **Path Length:** A valid parentheses string must be of even length. Since we only move down and right, the total length of any path is exactly `m + n - 1`. If this length is odd, it is impossible to form a valid string. Return `false` immediately.
   - **Start & End Characters:** A valid parentheses string must start with an open bracket `'('` and end with a closed bracket `')'`. If `grid[0][0] == ')'` or `grid[m-1][n-1] == '('`, return `false`.

2. **State Tracking (Memoization):**
   - Use recursion to explore moving down (`i+1`) and right (`j+1`).
   - Track current row `i`, current column `j`, and the `openCount`.
   - Max possible `openCount` is bounded by the grid dimensions (`m+n`).
   - Cache results in a 3D DP array `t[101][101][201]` to avoid redundant calculations.

3. **Bottom-Up DP Optimization:**
   - Map the recursion into a 3D table.
   - Iterate backward from the target `(m-1, n-1)` to the start `(0, 0)`.
   - At each cell `(i, j)`, calculate the required `openCount` to reach a valid state in adjacent cells (right and down).

## 💻 Solution Code

<details>
<summary><strong>Brute Force (Memoization)</strong></summary>

```cpp
// Intuition: We use DFS to explore all possible paths moving right and down. Instead of forming the entire string, we track an `openCount` to check for balance on the fly. We memoize visited states to optimize the overlapping subproblems.
// Approach:
// 1. Maintain an `openCount` (+1 for '(', -1 for ')').
// 2. Return false instantly if `openCount < 0` (unbalanced).
// 3. Early prune for odd path lengths and invalid start/end characters.
// 4. Memoize the state (i, j, openCount) in a 3D array to save computations.
// Time Complexity: O(m * n * (m + n)), where m and n are the dimensions. Max possible `openCount` is m+n.
// Space Complexity: O(m * n * (m + n)) for the 3D memoization array and the recursion stack.
class Solution {
public:
    int m, n;
    int t[101][101][201];

    bool solve(int i, int j, int openCount, vector<vector<char>>& grid) {
        // Adjust balance count based on current character
        openCount += (grid[i][j] == '(') ? 1 : -1;

        // If closing brackets exceed opening brackets, the path is invalid
        if(openCount < 0)
            return false;

        // Return the precomputed state if available
        if(t[i][j][openCount] != -1) {
            return t[i][j][openCount];
        }
        
        // Base case: successfully reached the bottom-right cell
        if(i == m-1 && j == n-1)
            return t[i][j][openCount] = (openCount == 0);

        // Move down if within boundaries
        if(i+1 < m) {
            if(solve(i+1, j, openCount, grid)) 
                return t[i][j][openCount] = true;
        }

        // Move right if within boundaries
        if(j+1 < n) {
            if(solve(i, j+1, openCount, grid)) 
                return t[i][j][openCount] = true;
        }

        // If neither direction yields a valid path, return false
        return t[i][j][openCount] = false;
    }

    bool hasValidPath(vector<vector<char>>& grid) {
        m = grid.size();
        n = grid[0].size();

        // A valid parenthesis string must always have an even length
        if((m+n-1) % 2 == 1) 
            return false;
        
        // The first char must be '(' and the last char must be ')'
        if(grid[0][0] == ')' || grid[m-1][n-1] == '(')
            return false;
        
        // Initialize memoization array with -1
        memset(t, -1, sizeof(t));

        // Start from cell (0,0) with 0 initial balance
        return solve(0, 0, 0, grid);

    }
};

/*
*
* Dry Run
* Given grid = [["(", "("], [")", ")"]]
* Size is 2x2. Total path length = 2 + 2 - 1 = 3 (Odd).
* Program hits the early rejection check `(m+n-1) % 2 == 1` and returns `false`.
* 
* For a valid 2x3 grid:
* Call `solve(0, 0, 0)` -> reads '(' -> `openCount` = 1.
* Moves right to (0,1) -> reads '(' -> `openCount` = 2.
* Moves down to (1,1) -> reads ')' -> `openCount` = 1.
* Moves right to (1,2) -> reads ')' -> `openCount` = 0.
* Base case reached, `openCount` == 0 -> returns `true`.
*
*/
```

<summary><strong>Optimized Solution (Bottom-Up DP)</strong></summary>

```cpp
// Intuition: We convert the top-down memoized approach into a bottom-up Dynamic Programming solution. By starting from the destination and working backward to the origin, we eliminate recursion stack overhead.
// Approach:
// 1. Initialize a 3D boolean array `t[i][j][openCount]`.
// 2. Handle early rejection base cases for odd lengths or invalid corners.
// 3. Iterate backward from `(m-1, n-1)` to `(0, 0)`.
// 4. For each cell, check all possible `openCount` values bounded by the steps taken so far (`i+j+1`).
// 5. Look up the required `newOpCount` at the right and down adjacent cells. If they can resolve to true, then the current state is true.
// Time Complexity: O(m * n * (m + n)), as we have 3 nested loops constrained by m and n.
// Space Complexity: O(m * n * (m + n)) used by the 3D boolean DP table.
class Solution {
public:
    int m, n;
    bool t[101][101][201];

    bool hasValidPath(vector<vector<char>>& grid) {
        m = grid.size();
        n = grid[0].size();

        // Path length must be even
        if((m+n-1) % 2 == 1)
            return false;

        // Path must start with '(' and end with ')'
        if (grid[0][0] != '(' || grid[m - 1][n - 1] != ')') {
            return false;
        }

        // Bottom-up evaluation starting from the destination cell
        for(int i = m-1; i >= 0; i--) {
            for(int j = n-1; j >= 0; j--) {

                // Loop through all possible valid balance counts for cell (i, j)
                for(int openCount = 0; openCount <= i+j+1; openCount++) {
                    
                    // Base condition for the final cell
                    if(i == m-1 && j == n-1) {
                        t[i][j][openCount] = (openCount == 0);
                        continue;
                    }

                    // Default state initialization
                    t[i][j][openCount] = false;

                    // Evaluate transition if moving down
                    if(i+1 < m) {
                        int newOpCount = (grid[i+1][j] == '(') ? openCount + 1 : openCount-1;
                        if(newOpCount >= 0 && t[i+1][j][newOpCount] == true) {
                            t[i][j][openCount] = true;
                        }
                    }

                    // Evaluate transition if moving right
                    if(j+1 < n) {
                        int newOpCount = (grid[i][j+1] == '(') ? openCount + 1 : openCount-1;
                        if(newOpCount >= 0 && t[i][j+1][newOpCount] == true) {
                            t[i][j][openCount] = true;
                        }
                    }

                }

            }
        }

        // Return the DP result at the start cell with openCount 1 (since grid[0][0] is always '(')
        return t[0][0][1];
        
    }
};

/*
*
* Dry Run
* We define `t[i][j][openCount]` as: "If I am at cell (i, j) holding `openCount` unmatched '('s, can I reach the end successfully?"
* 
* Start DP at (m-1, n-1): t[m-1][n-1][0] is `true`, all other openCounts are `false`.
* Step backward to (m-2, n-1) and (m-1, n-2).
* At any cell (i, j), we assume we hold an `openCount`. If we move down, the next cell will either increase or decrease our balance.
* If that resulting balance `newOpCount` at the adjacent cell is marked `true`, then our current `openCount` at (i,j) is also valid (`true`).
* 
* Finally, we return `t[0][0][1]` because starting at (0,0) ensures our first character is '(', giving us an immediate openCount of 1 before moving to the next cells.
*
*/
```

## 📌 Notes
- **Early Exits:** Adding the constant time mathematical checks `(m + n - 1) % 2 == 1` and boundary string validations strictly trims unresolvable branches.
- **Why `openCount <= i+j+1`:** In the Bottom-Up dynamic approach, an optimization is to bound the nested loop. `openCount` at any `(i,j)` can't possibly exceed the number of total steps taken to get to that cell `(i + j + 1)`.

## 🗝️ Key Insights
- Managing paths through strings can frequently be broken down into integer manipulations (increment/decrement counting) instead of heavy string concatenation.
- If at any point the number of closing brackets strictly outnumbers opening brackets (`openCount < 0`), that specific sequence is irrecoverably flawed.
