## 📜 Problem Statement

You are given a string `s` and a positive integer `k`.

Select a set of **non-overlapping** substrings from the string `s` that satisfy the following conditions:
1. The length of each substring is **at least** `k`.
2. Each substring is a **palindrome**.

Return *the **maximum** number of substrings in an optimal selection*.

A **substring** is a contiguous sequence of characters within a string.

---

## 🔒 Constraints

* $1 \le k \le s.\text{length} \le 2000$
* `s` consists of lowercase English letters.

## 🧪 Examples

| Example | Input | Output | Explanation |
| :---: | :--- | :---: | :--- |
| **1** | `s = "abaccdbbd"`, `k = 3` | **`2`** | Selected non-overlapping substrings: `s = "aba"` (len 3) and `s = "dbbd"` (len 4). Both are valid palindromes of length $\ge 3$. |
| **2** | `s = "adbcda"`, `k = 2` | **`0`** | No palindromic substring of length $\ge 2$ exists in `s`. |

## 🧠 Thought Process & Problem Analysis

### 1. Beginner Intuition & Special Cases
When faced with selecting non-overlapping segments to maximize count, dynamic programming or greedy choices naturally emerge.

* **Special Case ($k = 1$):** Every individual character is a valid palindrome of length $\ge 1$. Hence, if $k = 1$, the answer is simply $n$ (the length of the string `s`).
* **General Case ($k > 1$):** We must identify substrings $s[i..j]$ of length $\ge k$ that form palindromes. Since we want non-overlapping substrings, once we pick a palindrome ending at index $j$, the search for the next palindrome starts strictly from $j+1$.

### 2. Decision Tree & Subproblems
For any substring window $s[i..j]$:
1. **Check Palindrome:** Is $s[i..j]$ a palindrome?
   * **Take It:** Count $+1$ and recursively solve for the remaining suffix starting at index $j+1$.
   * **Grow Window:** Expand the right boundary ($j \to j+1$) to attempt forming a larger valid palindrome.
   * **Slide Window:** Shift both boundaries right ($i \to i+1, j \to j+1$) to preserve minimal length requirements.

### 3. $O(1)$ Palindrome Verification ("The Palindromic Blueprint")
Verifying if a substring $s[i..j]$ is a palindrome naively takes $O(n)$ time. Inside $O(n^2)$ DP states, this inflates overall time complexity to $O(n^3)$. 

To optimize to $O(n^2)$, we can precompute a 2D boolean matrix `isPalindrome[i][j]` using **Interval Dynamic Programming**:
* **Length 1:** `isPalindrome[i][i] = true`
* **Length 2:** `isPalindrome[i][j] = (s[i] == s[j])` when $j = i + 1$
* **Length > 2:** `isPalindrome[i][j] = (s[i] == s[j]) && isPalindrome[i+1][j-1]`

### 1️⃣ Approach 1: Simple Recursion & Memoization ($O(n^3)$)

```cpp
// Intuition: Recursively explore window states [i..j], checking if s[i..j] is a palindrome on the fly.
// Approach: Top-down recursion with a 2D memoization table t[i][j] storing state answers.
// Time Complexity: O(n^3) - n^2 states multiplied by O(n) palindrome checks.
// Space Complexity: O(n^2) - for the 2D memoization matrix and recursion stack.
class Solution {
public:
    // Check if substring s[i..j] is a palindrome
    bool isPalindrome(const string& s, int i, int j) {
        while (i < j) {
            if (s[i++] != s[j--]) return false; // Mismatch found
        }
        return true; // Valid palindrome
    }

    // max non-overlapping palindromic pieces (length >= k) from s[i..j]
    int solve(const string& s, int k, int i, int j, vector<vector<int>>& t) {
        int n = s.size();
        if (i >= n || j >= n) 
            return 0; // Base case: Out of bounds
            
        if (t[i][j] != -1) 
            return t[i][j]; // Return cached result

        if (isPalindrome(s, i, j)) {
            int growWindow  = solve(s, k, i, j + 1, t); // Expand right boundary
            int takeIt      = 1 + solve(s, k, j + 1, j + k, t); // Pick palindrome & jump
            int slideWindow = solve(s, k, i + 1, j + 1, t); // Shift window right

            return t[i][j] = max({growWindow, takeIt, slideWindow});
        }

        int slideWindow = solve(s, k, i + 1, j + 1, t); // Shift window right
        int growWindow  = solve(s, k, i, j + 1, t); // Expand right boundary

        return t[i][j] = max(slideWindow, growWindow);
    }

    int maxPalindromes(string s, int k) {
        int n = s.size();
        if (k == 1)
            return n; // each character can be a substring

        vector<vector<int>> t(n, vector<int>(n, -1)); // Memoization matrix

        return solve(s, k, 0, k - 1, t); // Start with minimum required window size
    }
};

/*
*
* Dry Run
* Input: s = "abaccdbbd", k = 3
* 1. k != 1, initialize DP table with -1.
* 2. Call solve(s, 3, 0, 2, t) for window "aba" (i=0, j=2).
* 3. "aba" is a palindrome:
*    - growWindow: solve(..., 0, 3) -> "abac"
*    - takeIt: 1 + solve(..., 3, 5) -> jump past "aba"
*    - slideWindow: solve(..., 1, 3) -> "bac"
* 4. Option takeIt recursively finds "dbbd" at s[5..8].
* 5. Total count = 1 + 1 = 2.
*
*/
```

### 2️⃣ Approach 2: Top-Down Recursion + $O(1)$ Palindrome Lookup ($O(n^2)$)

```cpp
// Intuition: Precompute all palindromic substrings using a 2D boolean table to achieve O(1) checks.
// Approach: Build the 2D isPalindrome table via interval DP, then solve recursively with memoization.
// Time Complexity: O(n^2) - O(n^2) precomputation + O(n^2) states with O(1) transitions.
// Space Complexity: O(n^2) - for the boolean palindrome table and memoization matrix.
class Solution {
public:
    vector<vector<bool>> isPalindrome;

    // max non-overlapping palindromic pieces (length >= k) from s[i..j]
    int solve(const string& s, int k, int i, int j, vector<vector<int>>& t) {
        int n = s.size();
        if (i >= n || j >= n) 
            return 0; // Out of bounds
            
        if (t[i][j] != -1) 
            return t[i][j]; // Cached state

        if (isPalindrome[i][j]) { // O(1) lookup
            int growWindow  = solve(s, k, i, j + 1, t); // Expand window
            int takeIt      = 1 + solve(s, k, j + 1, j + k, t); // Include palindrome
            int slideWindow = solve(s, k, i + 1, j + 1, t); // Slide window

            return t[i][j] = max({growWindow, takeIt, slideWindow});
        }

        int slideWindow = solve(s, k, i + 1, j + 1, t); // Slide window
        int growWindow  = solve(s, k, i, j + 1, t); // Expand window

        return t[i][j] = max(slideWindow, growWindow);
    }

    int maxPalindromes(string s, int k) {
        int n = s.size();
        if (k == 1)
            return n; // each character can be a substring

        isPalindrome.assign(n+1, vector<bool>(n+1));
        // Palindromic substring Blueprint
        for(int L = 1; L <= n; L++) {
            for(int i = 0; i+L <= n; i++) {
                int j = i + L - 1;

                if(i == j) {
                    isPalindrome[i][i] = true; // Single characters are palindrome
                } else if(i+1 == j) {
                    isPalindrome[i][j] = (s[i] == s[j]); // Strings of 2 Length
                } else {
                    isPalindrome[i][j] = ((s[i] == s[j]) && isPalindrome[i+1][j-1] == true);
                }
            }
        }

        vector<vector<int>> t(n, vector<int>(n, -1)); // DP table

        return solve(s, k, 0, k - 1, t);
    }
};

/*
*
* Dry Run
* Input: s = "adbcda", k = 2
* 1. Build isPalindrome matrix:
*    - Single characters are true.
*    - No length >= 2 substring is a palindrome.
* 2. Call solve(s, 2, 0, 1, t) for "ad".
* 3. isPalindrome[0][1] is false.
* 4. Recursion slides and grows window without finding valid palindromes.
* 5. Returns 0.
*
*/
```

### 3️⃣ Approach 3: Bottom-Up Dynamic Programming ($O(n^3)$)

```cpp
// Intuition: Transform top-down recursion into iterative bottom-up DP using a 2D table filled in reverse.
// Approach: Iterate i backwards from n-1 to 0 and j from n-1 to i using inline palindrome checking.
// Time Complexity: O(n^3) - nested loops O(n^2) with O(n) palindrome check inside.
// Space Complexity: O(n^2) - for the 2D DP table t[n+1][n+1].
class Solution {
public:
    // Helper function to check if s[i..j] is a palindrome
    bool isPalindrome(const string& s, int i, int j) {
        while (i < j) {
            if (s[i++] != s[j--]) return false; // Mismatch
        }
        return true; // Valid palindrome
    }

    int maxPalindromes(string s, int k) {
        int n = s.size();
        if (k == 1) 
            return n; // each character can be a substring

        vector<vector<int>> t(n + 1, vector<int>(n + 1, 0)); // DP table initialized to 0

        for (int i = n - 1; i >= 0; --i) {
            for (int j = n - 1; j >= i; --j) {

                if (isPalindrome(s, i, j)) {
                    int growWindow  = t[i][j + 1]; // Try larger palindrome
                    int takeIt      = 1 + (j + k <= n ? t[j + 1][j + k] : 0); // Pick & jump
                    int slideWindow = t[i + 1][j + 1]; // Shift window right

                    t[i][j] = max({growWindow, takeIt, slideWindow});
                }
                
                int slideWindow = t[i + 1][j + 1]; // Shift window
                int growWindow  = t[i][j + 1]; // Grow window
                t[i][j] = max({t[i][j], slideWindow, growWindow});
            }
        }

        return t[0][k - 1]; // Result starting at index 0 with length k
    }
};

/*
*
* Dry Run
* Input: s = "abaccdbbd", k = 3
* 1. Initialize DP table of size 10x10 with 0.
* 2. Outer loop i goes from 8 down to 0; inner loop j goes from 8 down to i.
* 3. At i=5, j=8 ("dbbd"), isPalindrome is true -> takeIt = 1 + t[9][12] = 1.
* 4. At i=0, j=2 ("aba"), isPalindrome is true -> takeIt = 1 + t[3][5] = 1 + 1 = 2.
* 5. t[0][2] stores answer = 2.
*
*/
```

### 4️⃣ Approach 4: Bottom-Up DP + $O(1)$ Palindrome Lookup ($O(n^2)$)

```cpp
// Intuition: Combine bottom-up iteration with precomputed O(1) palindrome matrix for optimal 2D evaluation.
// Approach: Compute boolean palindrome matrix via interval DP, then populate the 2D state DP table.
// Time Complexity: O(n^2) - O(n^2) for precomputation and O(n^2) for table filling.
// Space Complexity: O(n^2) - for 2D boolean matrix and 2D DP table.
class Solution {
public:
    int maxPalindromes(string s, int k) {
        int n = s.size();
        if (k == 1) 
            return n; // each character can be a substring

        vector<vector<bool>> isPalindrome(n, vector<bool>(n, false));

        // Palindromic substring Blueprint
        for(int L = 1; L <= n; L++) {
            for(int i = 0; i+L <= n; i++) {
                int j = i + L - 1;

                if(i == j) {
                    isPalindrome[i][i] = true; // Single characters are palindrome
                } else if(i+1 == j) {
                    isPalindrome[i][j] = (s[i] == s[j]); // Strings of 2 Length
                } else {
                    isPalindrome[i][j] = ((s[i] == s[j]) && isPalindrome[i+1][j-1] == true);
                }
            }
        }

        vector<vector<int>> t(n + 1, vector<int>(n + 1, 0)); // Bottom-up DP table

        for (int i = n - 1; i >= 0; --i) {
            for (int j = n - 1; j >= i; --j) {

                if (isPalindrome[i][j]) {
                    int growWindow  = t[i][j + 1]; // Grow window
                    int takeIt      = 1 + (j + k <= n ? t[j + 1][j + k] : 0); // Pick & jump
                    int slideWindow = t[i + 1][j + 1]; // Slide window

                    t[i][j] = max({growWindow, takeIt, slideWindow});
                }
                
                int slideWindow = t[i + 1][j + 1]; // Slide window
                int growWindow  = t[i][j + 1]; // Grow window
                t[i][j] = max({t[i][j], slideWindow, growWindow});
            }
        }

        return t[0][k - 1]; // Final result
    }
};

/*
*
* Dry Run
* Input: s = "abaccdbbd", k = 3
* 1. Precompute isPalindrome matrix in O(n^2) time.
* 2. isPalindrome[0][2] ("aba") = true, isPalindrome[5][8] ("dbbd") = true.
* 3. Fill bottom-up DP table from bottom to top.
* 4. Returns t[0][2] = 2.
*
*/
```

### 5️⃣ Approach 5: Length-Based Top-Down DP + $O(1)$ Palindrome Matrix ($O(n^2)$)

```cpp
// Intuition: Frame DP states around prefix length 'n', testing palindrome endings at character s[n-1].
// Approach: Recursively compute solve(n, k) by either skipping s[n-1] or picking a palindrome ending at s[n-1].
// Time Complexity: O(n^2) - n states with an inner loop running at most n times using O(1) palindrome checks.
// Space Complexity: O(n^2) - for 2D palindrome matrix and 1D DP memoization array.
class Solution {
public:
    vector<vector<bool>> isPalindrome;
    vector<int> t;

    int solve(int n, int k) {
        if (n < k) return 0; // Base case: prefix too short

        if (t[n] != -1) 
            return t[n]; // Return cached value

        int result = solve(n - 1, k); // ignore the current character s[n-1]

        int j = n - 1;
        // end the current palindrome at the current character s[n-1]
        for (int i = 0; j-i+1>=k; i++) {
            if (isPalindrome[i][j]) {
                result = max(result, 1 + solve(i, k)); // Pick palindrome s[i..j]
            }
        }

        return t[n] = result;
    }

    int maxPalindromes(string s, int k) {
        int n = s.length();
        isPalindrome.assign(n, vector<bool>(n, false));

        // Build palindrome lookup table
        for (int L = 1; L <= n; L++) {
            for (int i = 0; i + L <= n; i++) {
                int j = i + L - 1;

                if (i == j) {
                    isPalindrome[i][i] = true;
                } else if (i + 1 == j) {
                    isPalindrome[i][j] = (s[i] == s[j]);
                } else {
                    isPalindrome[i][j] = ((s[i] == s[j]) && isPalindrome[i+1][j-1] == true);
                }
            }
        }

        t.assign(n + 1, -1); // 1D memoization array
        return solve(n, k);
    }
};

/*
*
* Dry Run
* Input: s = "abaccdbbd", k = 3 (n = 9)
* 1. solve(9, 3):
*    a. Option 1: result = solve(8, 3) (ignore last char 'd')
*    b. Option 2: j = 8, test i = 5 ("dbbd", len = 4 >= 3).
*       isPalindrome[5][8] is true -> result = max(result, 1 + solve(5, 3)).
* 2. solve(5, 3) evaluates prefix "abacc":
*    a. j = 2 ("aba", len = 3 >= 3) -> isPalindrome[0][2] is true -> 1 + solve(0, 3) = 1.
* 3. Combining results gives 1 + 1 = 2.
*
*/
```

### 6️⃣ Approach 6: Length-Based Bottom-Up 1D DP + $O(1)$ Palindrome Matrix ($O(n^2)$)

```cpp
// Intuition: Convert the prefix-length recursion (Approach 5) into a clean 1D bottom-up iterative DP.
// Approach: Populate 1D DP table t[len] from len = k to n using the precomputed boolean palindrome matrix.
// Time Complexity: O(n^2) - outer loop for prefix lengths, inner loop for starting positions.
// Space Complexity: O(n^2) - for 2D palindrome matrix and O(n) for 1D DP table.
class Solution {
public:
    vector<vector<bool>> isPalindrome;
    vector<int> t;

    int maxPalindromes(string s, int k) {
        int n = s.length();
        isPalindrome.assign(n, vector<bool>(n, false));

        // Palindromic precomputation blueprint
        for (int L = 1; L <= n; L++) {
            for (int i = 0; i + L <= n; i++) {
                int j = i + L - 1;

                if (i == j) {
                    isPalindrome[i][i] = true;
                } else if (i + 1 == j) {
                    isPalindrome[i][j] = (s[i] == s[j]);
                } else {
                    isPalindrome[i][j] = ((s[i] == s[j]) && isPalindrome[i+1][j-1] == true);
                }
            }
        }

        t.assign(n + 1, -1);
        // base case
        for(int len = 0; len < k; len++) {
            t[len] = 0; // if (n < k) return 0;
        }

        for (int len = k; len <= n; len++) {

            int result = t[len - 1];      // int result = solve(n - 1, k);

            int j = len - 1;
            for (int i = 0; j-i+1 >= k; i++) {
                if (isPalindrome[i][j]) {
                    result = max(result, 1 + t[i]);   // result = max(result, 1 + solve(i, k));
                }
            }

            t[len] = result;              // return t[n] = result;
        }

        return t[n];                      // return solve(n, k);
    }
};

/*
*
* Dry Run
* Input: s = "abaccdbbd", k = 3
* 1. Initialize t array of size 10 with -1.
* 2. Set t[0] = 0, t[1] = 0, t[2] = 0.
* 3. Iterate len from 3 to 9:
*    - len = 3: j = 2, i = 0 ("aba") -> isPalindrome[0][2] = true -> t[3] = max(t[2], 1 + t[0]) = 1.
*    - len = 4 to 8: update values accordingly.
*    - len = 9: j = 8, i = 5 ("dbbd") -> isPalindrome[5][8] = true -> t[9] = max(t[8], 1 + t[5]) = 2.
* 4. Return t[9] = 2.
*
*/
```

## 💡 Key Insights & Complexity Comparison

| Approach | Precomputation | DP State Dim. | Time Complexity | Space Complexity |
| :--- | :---: | :---: | :---: | :---: |
| **Approach 1: Simple Recursion** | None | 2D (`n x n`) | $O(n^3)$ | $O(n^2)$ |
| **Approach 2: Top-Down + Blueprint** | $O(n^2)$ | 2D (`n x n`) | $O(n^2)$ | $O(n^2)$ |
| **Approach 3: Bottom-Up DP** | None | 2D (`n x n`) | $O(n^3)$ | $O(n^2)$ |
| **Approach 4: Bottom-Up + Blueprint** | $O(n^2)$ | 2D (`n x n`) | $O(n^2)$ | $O(n^2)$ |
| **Approach 5: Length Top-Down** | $O(n^2)$ | 1D (`n+1`) | $O(n^2)$ | $O(n^2)$ |
| **Approach 6: Length Bottom-Up** | $O(n^2)$ | 1D (`n+1`) | **$O(n^2)$** | **$O(n^2)$** |

> 🌟 **Greedy Strategy Optimization Notice:** 
> Palindromes of length $k$ or $k+1$ are sufficient to consider because any longer palindrome contains a smaller palindrome of length $k$ or $k+1$ within it. This property can be leveraged to reduce the inner search space even further in greedy variations!
