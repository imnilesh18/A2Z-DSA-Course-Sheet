## 📌 Problem Statement

You are given a string `word` containing **distinct** lowercase English letters.

Telephone keypads have keys numbered `2` to `9` mapped with distinct collections of lowercase English letters, which can be used to form words by pushing them. For example, key `2` might be mapped to `["a", "b", "c"]`, where pushing the key once types `"a"`, twice types `"b"`, and three times types `"c"`.

It is allowed to **remap** the keys numbered `2` to `9` to distinct collections of letters. The keys can be remapped to any amount of letters, but each letter must be mapped to **exactly one** key.

Return the *minimum number of pushes* needed to type the string `word` after remapping the keys.

---

## 🔒 Constraints

* `1 <= word.length <= 26`
* `word` consists of lowercase English letters.
* All letters in `word` are **distinct**.

## 🧠 Approach & Explanation

The problem asks us to minimize key presses when remapping characters to a standard telephone keypad (keys `2` through `9`, giving **8 available keys** in total).

### Strategy Breakdown

1. **Greedy Key Assignment**:
   - Since we have 8 available keys (`2, 3, 4, 5, 6, 7, 8, 9`), the most efficient strategy is to distribute characters evenly across all 8 keys.
   - The **first 8 characters** placed on keys 2–9 will each require **1 push**.
   - The **next 8 characters** (positions 9 to 16) placed on keys 2–9 will require **2 pushes** each.
   - The **next 8 characters** (positions 17 to 24) will require **3 pushes** each, and so on.

2. **Mathematical Formula**:
   - For a 0-indexed position `i` in the sorted frequency/character array:
     $$\text{Pushes required for } i\text{-th character} = \left(\lfloor \frac{i}{8} \rfloor + 1\right)$$
   - Total Pushes = $\sum_{i=0}^{N-1} \left( \text{Frequency}[i] \times \left( \lfloor \frac{i}{8} \rfloor + 1 \right) \right)$

## 💻 Solution Code

### Approach 1: Keypad Map Simulation

```cpp
// Intuition:
// We can simulate assigning each character to telephone keypad keys (from 2 to 9) sequentially.
// Since each key can hold multiple characters, the number of pushes needed for a character on a key 
// equals the total number of characters currently mapped to that key.
//
// Approach:
// 1. If word length <= 8, each letter gets its own key, requiring only 1 push each (total = word.length()).
// 2. Iterate through each character in the string.
// 3. Maintain an 'assign' variable pointing to keypad keys (2 through 9).
// 4. Increment the count of characters on the assigned key and add this count to total pushes.
// 5. Cycle 'assign' back to 2 whenever it exceeds 9.
//
// Time Complexity: O(N) where N is the length of the string 'word'.
// Space Complexity: O(1) auxiliary space as the hash map size is bounded by keys 2 through 9.

class Solution {
public:
    int minimumPushes(string word) {
        if(word.length() <= 8) {
            return word.length(); // Quick return: up to 8 letters need 1 push each
        }
        
        int count = 0; // Tracks total key presses
        unordered_map<int, int> mp; // You can use an array of size 10 also and use index 2 to 9
        
        int assign = 2; // Keypad buttons start from key 2 to key 9
        for(char &ch : word) {
            
            if(assign > 9) {
                assign = 2; // Reset back to key 2 after reaching key 9
            }
            
            mp[assign]++; // Map character to key and increment character count on this key
            count += mp[assign]; // Add current depth/push requirement for this key
            assign++; // Move to next keypad key
        }
        
        return count; // Total minimum pushes
        
    }
};

/*
*
* Dry Run
*
* Input: word = "xycdefghij" (length = 10)
* Initial: count = 0, assign = 2
* 
* Char 'x': assign = 2, mp[2] = 1, count += 1 = 1, assign = 3
* Char 'y': assign = 3, mp[3] = 1, count += 1 = 2, assign = 4
* Char 'c': assign = 4, mp[4] = 1, count += 1 = 3, assign = 5
* Char 'd': assign = 5, mp[5] = 1, count += 1 = 4, assign = 6
* Char 'e': assign = 6, mp[6] = 1, count += 1 = 5, assign = 7
* Char 'f': assign = 7, mp[7] = 1, count += 1 = 6, assign = 8
* Char 'g': assign = 8, mp[8] = 1, count += 1 = 7, assign = 9
* Char 'h': assign = 9, mp[9] = 1, count += 1 = 8, assign = 10
* Char 'i': assign = 10 -> resets to 2, mp[2] = 2, count += 2 = 10, assign = 3
* Char 'j': assign = 3, mp[3] = 2, count += 2 = 12, assign = 4
* 
* Output: 12
*
*/
```

### Approach 2: Greedy & Frequency Math (Generalized)

```cpp
// Intuition:
// To minimize total key pushes, characters with higher frequencies should be placed in 
// primary positions (requiring 1 push), followed by secondary positions (2 pushes), and so on.
// Since there are 8 keypad keys (2 to 9), the first 8 characters take 1 push, the next 8 take 2 pushes, etc.
//
// Approach:
// 1. Calculate frequency of each character in 'word'.
// 2. Sort frequencies in descending order to process higher frequencies first.
// 3. For the i-th character in sorted order, the push count required is (i / 8) + 1.
// 4. Sum up (frequency * pushes) for all 26 possible lowercase English characters.
//
// Time Complexity: O(N) where N is the length of word, plus O(26 log 26) for sorting 26 elements, which simplifies to O(N).
// Space Complexity: O(1) auxiliary space as fixed-size vector of size 26 is used.

class Solution {
public:
    int minimumPushes(string word) {
        
        // Generic solution
        vector<int> mp(26, 0); // Frequency array for 26 lowercase English letters
        for(char &ch: word)
            mp[ch - 'a'] = 1; // Mentioned in qn, all letters will be distinct
    
        sort(begin(mp), end(mp), greater<int>()); // descending order of frequency
        
        int ans = 0; // Accumulator for total pushes
        for(int i = 0; i < 26; i++){
            ans += mp[i]*((i/8) + 1); // (i/8)+1 gives 1 push for first 8, 2 for next 8, etc.
        }
        return ans; // Return minimal pushes required
    }
};

/*
*
* Dry Run
*
* Input: word = "abcde" (length = 5)
* Frequency Array: mp['a']..mp['e'] set to 1, others 0
* Sorted Frequencies: [1, 1, 1, 1, 1, 0, 0, ...]
* 
* Loop i = 0 to 4:
* i = 0: mp[0] = 1, pushes = (0/8)+1 = 1, ans += 1*1 = 1
* i = 1: mp[1] = 1, pushes = (1/8)+1 = 1, ans += 1*1 = 2
* i = 2: mp[2] = 1, pushes = (2/8)+1 = 1, ans += 1*1 = 3
* i = 3: mp[3] = 1, pushes = (3/8)+1 = 1, ans += 1*1 = 4
* i = 4: mp[4] = 1, pushes = (4/8)+1 = 1, ans += 1*1 = 5
* i = 5..25: mp[i] = 0, ans remains 5
* 
* Output: 5
*
*/
```

## 🔑 Key Insights

- **Keypad Capacity**: Keys 2 through 9 provide **8 total keys** to assign characters.
- **Uniform vs. Frequency-based**: Because all characters in Part I are **distinct**, frequency sorting is trivial (all are `1`). However, **Approach 2** seamlessly scales to solve **LeetCode 3016 (Minimum Number of Pushes to Type Word II)** where duplicate character frequencies must be handled greedily.
- **Mathematical Optimization**: Index integer division `(i / 8) + 1` directly provides the push cost without simulating key assignments.
