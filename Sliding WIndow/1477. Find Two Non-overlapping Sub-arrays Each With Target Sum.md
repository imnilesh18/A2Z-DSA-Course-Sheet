## 📝 Problem Statement

You are given an array of integers `arr` and an integer `target`.

You have to find **two non-overlapping sub-arrays** of `arr` each with a sum equal to `target`. There can be multiple answers, so you have to find an answer where the **sum of the lengths of the two sub-arrays is minimum**.

Return the *minimum sum of the lengths of the two required sub-arrays*, or return `-1` if you cannot find two such sub-arrays.

---

## 🔢 Constraints

* $1 \le \text{arr.length} \le 10^5$
* $1 \le \text{arr}[i] \le 1000$
* $1 \le \text{target} \le 10^8$

## 🧠 Algorithmic Thinking & Approach

### 1. Intuition Behind Sliding Window
Because all array elements are positive ($\text{arr}[i] \ge 1$), any contiguous sub-array sum grows monotonically as we expand the window and shrinks monotonically as we contract it. This property naturally suggests a **Sliding Window** approach.

### 2. Overcoming the Non-Overlapping Challenge
Finding sub-arrays with a target sum is standard, but pairing two **non-overlapping** sub-arrays with minimum combined length requires extra care.
* A simple global `minLen` variable fails because two valid sub-arrays might overlap (e.g., in `[1, 6, 1]` with target `7`, `[1, 6]` and `[6, 1]` overlap).
* To prevent overlap, when we find a valid sub-array ending at index $j$ and starting at index $i$, we must ask: **"What was the shortest valid sub-array that ended at or before index $i - 1$?"**

### 3. Dynamic Programming + Sliding Window Strategy
To look up past sub-array information efficiently:
1. Maintain a dynamic programming array `minBestLenTillIdx` of size $N$, where `minBestLenTillIdx[k]` stores the **minimum length of a valid target sub-array seen up to index $k$**.
2. Expand the right pointer $j$ and update `currSum`.
3. If `currSum > target`, shrink from left ($i++$) until `currSum <= target`.
4. When `currSum == target`:
   - Calculate current window length: $\text{len} = j - i + 1$.
   - If a valid non-overlapping sub-array exists before index $i$ ($i > 0$ and $\text{minBestLenTillIdx}[i-1] \neq \infty$), update `result`:
     $$\text{result} = \min(\text{result}, \text{len} + \text{minBestLenTillIdx}[i-1])$$
   - Update the best single sub-array length seen so far:
     $$\text{bestMinLen} = \min(\text{bestMinLen}, \text{len})$$
5. Record `minBestLenTillIdx[j] = bestMinLen` and advance $j$.

## 💻 Solution Code

### Brute Force / Hash Map Solution

```cpp
// Intuition:
// Store prefix sums in a hash map to find all valid sub-arrays with target sum, then check all pairs for non-overlapping criteria.
// Approach:
// 1. Compute prefix sums and use a hash map to find all sub-arrays ending at index `r` with start index `l`.
// 2. Collect all valid intervals [l, r] along with their lengths.
// 3. Iterate through all pairs of valid intervals, ensuring they do not overlap, and track the minimum combined length.
// Time Complexity: O(N^2) in the worst case due to pairwise comparisons of valid sub-arrays.
// Space Complexity: O(N) to store prefix sums and valid sub-array intervals.

class SolutionBruteForce {
public:
    int minSumOfLengths(vector<int>& arr, int target) {
        int n = arr.size();
        vector<pair<int, int>> intervals; // Stores {start, end} of target subarrays
        
        unordered_map<int, int> prefixMap;
        prefixMap[0] = -1;
        int sum = 0;
        
        // Find all sub-arrays with sum equal to target
        for (int i = 0; i < n; i++) {
            sum += arr[i];
            if (prefixMap.find(sum - target) != prefixMap.end()) {
                intervals.push_back({prefixMap[sum - target] + 1, i});
            }
            prefixMap[sum] = i;
        }
        
        int result = INT_MAX;
        int m = intervals.size();
        
        // Pairwise comparison for non-overlapping sub-arrays
        for (int i = 0; i < m; i++) {
            for (int j = i + 1; j < m; j++) {
                // Check if interval i and interval j are non-overlapping
                if (intervals[i].second < intervals[j].first || intervals[j].second < intervals[i].first) {
                    int len1 = intervals[i].second - intervals[i].first + 1;
                    int len2 = intervals[j].second - intervals[j].first + 1;
                    result = min(result, len1 + len2);
                }
            }
        }
        
        return result == INT_MAX ? -1 : result;
    }
};

/*
*
* Dry Run
*
* Input: arr = [3, 2, 2, 4, 3], target = 3
* Intervals found: [0, 0] (len 1), [4, 4] (len 1)
* Check pair ([0, 0], [4, 4]):
* - Non-overlapping? Yes (0 < 4).
* - Total length = 1 + 1 = 2.
* Result = 2.
*
*/
```

### Optimized Solution (Sliding Window + DP)

```cpp
// Intuition:
// Use sliding window to find valid sub-arrays and an auxiliary array `minBestLenTillIdx` to keep track of the minimum sub-array length seen up to any index. This allows O(1) lookup for non-overlapping previous sub-arrays.
// Approach:
// 1. Maintain sliding window pointers `i` and `j` along with `currSum`.
// 2. Expand window by adding `arr[j]`. Shrink from left while `currSum > target`.
// 3. When `currSum == target`, calculate window length `len = j - i + 1`.
// 4. Look up `minBestLenTillIdx[i-1]` to check if a non-overlapping valid sub-array exists before index `i`.
// 5. If found, update `result` with `len + minBestLenTillIdx[i-1]`.
// 6. Update `bestMinLen` and record it in `minBestLenTillIdx[j]`.
// Time Complexity: O(N) - Each element is visited at most twice by pointers `i` and `j`.
// Space Complexity: O(N) - Uses an array of size N to memoize minimum lengths per index.

class Solution {
public:
    int minSumOfLengths(vector<int>& arr, int target) {
        int n = arr.size(); // Size of the input array

        int i = 0; // Left window pointer
        int j = 0; // Right window pointer

        int currSum = 0; // Running sum of current window
        vector<int> minBestLenTillIdx(n, INT_MAX); // Stores min subarray length seen up to index k

        int bestMinLen = INT_MAX; // Tracks best min subarray length found so far
        int result = INT_MAX;     // Stores overall minimum sum of two non-overlapping lengths


        while(j < n) {
            currSum += arr[j]; // Expand window to the right

            // Shrink window from left if current sum exceeds target
            while(i < j && currSum > target) {
                currSum -= arr[i++];
            }

            // Found a valid subarray with sum equal to target
            if(currSum == target) {
                int len = j - i + 1; // Current valid subarray length

                // Check if a non-overlapping valid subarray exists before index i
                if(i > 0 && minBestLenTillIdx[i-1] != INT_MAX) {
                    result = min(result, len + minBestLenTillIdx[i-1]);
                }

                // Update best minimum length seen so far
                bestMinLen = min(bestMinLen, len);
            }

            // Record best minimum length up to current index j
            minBestLenTillIdx[j] = bestMinLen;
            j++; // Move right pointer
        }

        // Return result if valid pair found, otherwise -1
        return result == INT_MAX ? -1 : result;
    }
};

/*
*
* Dry Run
*
* Example: arr = [3, 2, 2, 4, 3], target = 3
* 
* Initial State:
* n = 5, i = 0, j = 0, currSum = 0
* minBestLenTillIdx = [INF, INF, INF, INF, INF]
* bestMinLen = INF, result = INF
* 
* Step 1 (j = 0, arr[0] = 3):
* - currSum = 3 == target
* - len = 0 - 0 + 1 = 1
* - i = 0 (no element before index 0)
* - bestMinLen = min(INF, 1) = 1
* - minBestLenTillIdx[0] = 1
* 
* Step 2 (j = 1, arr[1] = 2):
* - currSum = 3 + 2 = 5 > target -> shrink: currSum -= arr[0], i = 1, currSum = 2
* - minBestLenTillIdx[1] = bestMinLen = 1
* 
* Step 3 (j = 2, arr[2] = 2):
* - currSum = 2 + 2 = 4 > target -> shrink: currSum -= arr[1], i = 2, currSum = 2
* - minBestLenTillIdx[2] = bestMinLen = 1
* 
* Step 4 (j = 3, arr[3] = 4):
* - currSum = 2 + 4 = 6 > target -> shrink: currSum -= arr[2], i = 3, currSum = 4
* - minBestLenTillIdx[3] = bestMinLen = 1
* 
* Step 5 (j = 4, arr[4] = 3):
* - currSum = 4 + 3 = 7 > target -> shrink: currSum -= arr[3], i = 4, currSum = 3 == target
* - len = 4 - 4 + 1 = 1
* - i = 4 > 0 and minBestLenTillIdx[3] = 1 != INF
* - result = min(INF, 1 + minBestLenTillIdx[3]) = 1 + 1 = 2
* - bestMinLen = min(1, 1) = 1
* - minBestLenTillIdx[4] = 1
* 
* Final Output: result = 2
*
*/
```

## 🔑 Key Insights

* **Monotonic Property:** Since all elements $\text{arr}[i] \ge 1$, sliding window logic guarantees $O(N)$ time for finding individual sub-arrays.
* **Non-Overlapping Constraint:** Solved dynamically by recording prefix answers (`minBestLenTillIdx[i-1]`) so that when the right sub-array $[i \dots j]$ is identified, it combines in $O(1)$ with the best left sub-array strictly before $i$.
* **Space vs Time Tradeoff:** Using $O(N)$ extra memory avoids nested loops or interval intersection checks, reducing time complexity from $O(N^2)$ to $O(N)$.

## 📌 Notes & Edge Cases

* **No valid pair:** If `result` remains `INT_MAX`, return `-1`.
* **Single valid sub-array:** If only one sub-array sums to `target`, `result` will never update, correctly returning `-1`.
* **All elements equal to target:** Handled properly as sub-arrays of length 1 will pair up with adjacent indices.

## 🚀 Further Exploration

* **What if numbers could be negative?** Sliding window won't work due to loss of monotonicity. You would use Prefix Sums + Hash Map combined with Dynamic Programming.
* **Generalization to $K$ sub-arrays:** Find $K$ non-overlapping sub-arrays each with target sum $\rightarrow$ Can be solved using DP where $\text{dp}[k][i]$ represents the minimum length sum using $k$ non-overlapping sub-arrays up to index $i$.
