# 3723. Maximize Sum of Squares of Digits

**Problem Link:** [Maximize Sum of Squares of Digits](https://leetcode.com/problems/maximize-sum-of-squares-of-digits/description/)
**Difficulty:** Medium
**Tags:** Math, Greedy

---

## 📝 Problem Statement

You are given two positive integers `num` and `sum`.

A positive integer `n` is **good** if it satisfies both of the following:
1. The number of digits in `n` is exactly `num`.
2. The sum of digits in `n` is exactly `sum`.

The **score** of a good integer `n` is the sum of the squares of digits in `n`.

Return a string denoting the good integer `n` that achieves the maximum score. If there are multiple possible integers, return the maximum one. If no such integer exists, return an empty string.

---

## ⚙️ Constraints

- `1 <= num <= 2 * 10^5`
- `1 <= sum <= 2 * 10^6`

## 🧠 Approach & Explanation

To maximize the sum of squares of the digits, we must use a **Greedy Approach**. 

Mathematically, the sum of squares is maximized when the variance between the numbers is as high as possible. For instance, if our target sum is 12, dividing it equally into `6` and `6` yields a sum of squares of $6^2 + 6^2 = 72$. However, heavily skewing it to `9` and `3` yields $9^2 + 3^2 = 90$. Therefore, we should always greedily pick the largest possible digit, which is `9`.

**Step-by-step logic:**
1. **Edge Case Validation:** If the requested `sum` is greater than what is mathematically possible with `num` digits (i.e., every digit is a `9`, so `num * 9`), we return an empty string `""`.
2. **Count the 9s:** Calculate how many `9`s we can place using `sum / 9`.
3. **Find the Remainder:** The leftover sum that couldn't form a full `9` is found using `sum % 9`. 
4. **Construct the Number:** 
   - Append the maximum number of `9`s.
   - Append the remainder digit (if it is greater than `0`).
   - Fill all remaining required positions with `0`s (since `0` adds nothing to the sum but satisfies the length requirement `num`).

## 💻 Solution Code

```cpp
// Intuition: To maximize the sum of squares of digits for a given sum, we must greedily use the largest possible digit (9). The mathematical property of squares means that larger individual numbers yield a greater sum of squares compared to distributing the sum evenly (e.g., 9^2 + 3^2 = 90 > 6^2 + 6^2 = 72).
// Approach: 
// 1. Check if it's impossible to reach the sum (i.e., if sum > num * 9). If so, return "".
// 2. Count how many 9s we can include by dividing sum by 9.
// 3. Find the remainder which will form the next digit.
// 4. Construct the string with the calculated 9s, append the remainder if it's > 0, and pad the rest with 0s to reach length 'num'.
// Time Complexity: O(num), as we construct a string of exactly 'num' digits.
// Space Complexity: O(1) auxiliary space, ignoring the space used for the output string.

class Solution {
public:
    string maxSumOfSquares(int num, int sum) {
        // If the sum exceeds the max possible sum with 'num' digits (all 9s)
        if(sum > num * 9)
            return "";
        
        // Calculate how many 9s we can greedily place
        int nines  = sum / 9;
        int remain = sum % 9;

        // Initialize result string with maximum 9s
        string result(nines, '9');

        // Append the remainder digit if it exists
        if(remain > 0) {
            result.push_back(remain + '0');
        }

        // Pad the remaining required digits with 0s
        result.append(num - result.length(), '0');

        return result;
    }
};

/*
*
* Dry Run
* Input: num = 5, sum = 21
* 1. Check: 21 > 5 * 9 (21 > 45) -> False
* 2. nines = 21 / 9 = 2
* 3. remain = 21 % 9 = 3
* 4. result initialized with two 9s: "99"
* 5. remain > 0 (3 > 0), append '3': result = "993"
* 6. Pad with 0s to reach length 5: result.append(5 - 3, '0') -> appends "00"
* 7. Final Result: "99300"
*
*/

```

## 🔑 Key Insights

* **Greedy is Optimal:** Squaring amplifies differences. When tasked with maximizing the sum of squares for a fixed sum, pulling values to their extremes (as many `9`s and `0`s as possible) will always yield a larger result than averaging the values out.
* **String Manipulation:** Using C++ `std::string` constructor `string(count, char)` and `append()` provides a highly optimized, O(N) way to build the result string without manually looping.
