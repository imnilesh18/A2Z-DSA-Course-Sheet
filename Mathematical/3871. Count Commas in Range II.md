## 📝 Problem Statement

Given an integer `n`, return the total number of commas used when writing all integers from `[1, n]` (inclusive) in standard number formatting.

In standard formatting:
- A comma is inserted after **every three digits** from the right.
- Numbers with fewer than $4$ digits contain no commas.

---

## ⚡ Constraints

- $1 \le n \le 10^{15}$

---

## 📊 Examples

| Example | Input | Output | Explanation |
| :--- | :--- | :--- | :--- |
| **Example 1** | `n = 1002` | `3` | The numbers `"1,000"`, `"1,001"`, and `"1,002"` each contain **1** comma, giving a total of $1 + 1 + 1 = 3$. |
| **Example 2** | `n = 998` | `0` | All numbers from $1$ to $998$ have fewer than $4$ digits. Therefore, **no** commas are used. |

---

## 💡 Intuition & Mathematical Pattern

Since $n$ can be as large as $10^{15}$, iterating through every number from $1$ to $n$ will cause a **Time Limit Exceeded (TLE)** error. Instead, we observe how comma counts increment exponentially at powers of $1000$ ($10^3$).

### Range Breakdown by Digit Magnitude

Comma counts remain constant across fixed numerical intervals:

| Range of Numbers | Digits | Commas per Number | Starting Threshold |
| :--- | :--- | :--- | :--- |
| $[1, 999]$ | $1 - 3$ | **0** | $1$ |
| $[10^3, 10^6 - 1]$ | $4 - 6$ | **1** | $1,000$ |
| $[10^6, 10^9 - 1]$ | $7 - 9$ | **2** | $1,000,000$ |
| $[10^9, 10^{12} - 1]$ | $10 - 12$ | **3** | $1,000,000,000$ |
| $[10^{12}, 10^{15} - 1]$ | $13 - 15$ | **4** | $1,000,000,000,000$ |

---

## 🛠️ Approaches

### Approach 1: Range-by-Range Simulation
1. Start at `lower = 1000` with `commas = 1`.
2. Compute the theoretical upper bound for the current range: `upper = lower * 1000 - 1`.
3. Cap `upper` at `n` if `upper > n`.
4. Calculate the total numbers in `[lower, upper]`: `count = upper - lower + 1`.
5. Accumulate `count * commas` into `result`.
6. Scale `lower` by $1000$ and increment `commas` by $1$.
7. Repeat while `lower <= n`.

### Approach 2: Simplified Threshold Prefix Contribution (Optimized & Clean)
Instead of processing individual non-overlapping ranges, count how many numbers reach each comma threshold:
- Every number $\ge 10^3$ contributes **at least 1 comma** $\implies (n - 10^3 + 1)$ commas.
- Every number $\ge 10^6$ contributes a **2nd comma** $\implies (n - 10^6 + 1)$ additional commas.
- Every number $\ge 10^9$ contributes a **3rd comma** $\implies (n - 10^9 + 1)$ additional commas.
- Every number $\ge 10^{12}$ contributes a **4th comma** $\implies (n - 10^{12} + 1)$ additional commas.

Summing these contributions across all threshold powers $10^{3k} \le n$ directly computes the total commas cleanly in $O(\log_{1000} n)$ time.

## 💻 Solution Code

### Approach 1: Range-by-Range Simulation

```cpp
// Intuition: Numbers acquire commas at logarithmic digit thresholds (every factor of 1000). By grouping numbers into ranges [10^3, 10^6 - 1], [10^6, 10^9 - 1], etc., each number within a range has a fixed count of commas.
// Approach: Maintain a lower bound starting at 1000 and commas starting at 1. Compute the upper bound for the range, cap it at n, calculate total numbers in that range, and multiply by the comma count. Then scale lower by 1000.
// Time Complexity: O(log1000(n)) - The loop executes at most 5-6 times since n <= 10^15.
// Space Complexity: O(1) - Uses constant auxiliary memory.

#define ll long long
class Solution {
public:
    long long countCommas(long long n) {
        ll result = 0;

        ll lower  = 1000; // First threshold where numbers receive 1 comma
        ll commas = 1;    // Initial comma count per number in current range

        while(lower <= n) {
            ll upper = lower * 1000 - 1; // Upper bound for current power range
            if(upper > n) upper = n;     // Cap upper bound at given input n

            ll countNumbers = upper - lower + 1; // Count of numbers in [lower, upper]
            result += (countNumbers * commas);  // Accumulate commas from this range

            lower *= 1000; // Scale lower bound to next power threshold
            commas++;      // Increment comma multiplier for next range
        }

        return result; // Return accumulated total commas
    }
};

/*
*
* Dry Run
*
* Input: n = 1002
* Initial State: result = 0, lower = 1000, commas = 1
*
* Iteration 1:
*   lower = 1000 <= 1002 (TRUE)
*   upper = 1000 * 1000 - 1 = 999999
*   upper > n (999999 > 1002) -> upper = 1002
*   countNumbers = 1002 - 1000 + 1 = 3
*   result += (3 * 1) -> result = 3
*   lower = 1000 * 1000 = 1000000
*   commas = 2
*
* Iteration 2:
*   lower = 1000000 <= 1002 (FALSE) -> Loop terminates
*
* Return: 3
*
*/
```

### Approach 2: Simplified Threshold Prefix Contribution

```cpp
// Intuition: Instead of counting commas range-by-range, we can count how many numbers reach each comma threshold. Every number >= 1000 adds 1 comma, every number >= 10^6 adds another comma, every number >= 10^9 adds a third, and so on.
// Approach: Start with threshold = 1000. While threshold <= n, add (n - threshold + 1) to result, representing all numbers >= threshold contributing one additional comma. Scale threshold by 1000 in each step.
// Time Complexity: O(log1000(n)) - Scales logarithmically with base 1000, running at most 5 iterations for n <= 10^15.
// Space Complexity: O(1) - Constant space complexity.

#define ll long long
class Solution {
public:
    long long countCommas(long long n) {
        ll result = 0;

        ll start = 1000; // First comma threshold (1,000)

        while(start <= n) {
            result += (n - start + 1); // Add 1 extra comma for all numbers >= start
            start *= 1000;             // Shift to next threshold (1,000,000; 1,000,000,000; etc.)
        }

        return result; // Return total commas
    }
};

/*
*
* Dry Run
*
* Input: n = 1002
* Initial State: result = 0, start = 1000
*
* Iteration 1:
*   start = 1000 <= 1002 (TRUE)
*   result += (1002 - 1000 + 1) -> result += 3 -> result = 3
*   start = 1000 * 1000 = 1000000
*
* Iteration 2:
*   start = 1000000 <= 1002 (FALSE) -> Loop terminates
*
* Return: 3
*
*/
```

## 🔍 Key Insights & Notes

- **Large Constraints Handling ($n \le 10^{15}$):** Linear $O(n)$ iteration will fail. Computing range sizes directly via mathematical powers achieves an optimal $O(\log_{1000} n)$ runtime.
- **Data Type Safety:** Since $n \le 10^{15}$, calculations overflow 32-bit standard signed integers (`2 * 10^9`). Always use `long long` in C++ to prevent integer overflow.
- **Equivalence of Approaches:** Approach 1 partitions numbers into non-overlapping ranges, while Approach 2 sums prefix threshold counts. Both are mathematically identical and run in constant operations for $n \le 10^{15}$.
