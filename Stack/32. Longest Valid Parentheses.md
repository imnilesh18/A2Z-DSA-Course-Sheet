## 📝 Problem Statement

Given a string containing just the characters `'('` and `')'`, return the length of the longest valid (well-formed) parentheses substring.

## ⛔ Constraints

- `0 <= s.length <= 3 * 10^4`
- `s[i]` is `'('`, or `')'`.

## 💡 Examples

| Example | Input | Output | Explanation |
| :--- | :--- | :--- | :--- |
| **Example 1** | `s = "(()"` | `2` | The longest valid parentheses substring is `"()"`. |
| **Example 2** | `s = ")()())"` | `4` | The longest valid parentheses substring is `"()()"`. |
| **Example 3** | `s = ""` | `0` | The string is empty, so there are no valid parentheses. |

---

## 🔍 Key Insights

1. **Balance is Key:** A valid parentheses substring must always have an equal number of opening and closing brackets. Furthermore, at no point while reading from left to right can the number of closing brackets exceed the number of opening brackets.
2. **The Left-to-Right Blindspot:** If we only traverse from left to right, we might miss valid substrings in cases where there are extra opening brackets that never get closed (e.g., `"(()"`). In this scenario, the `open` count stays higher than the `close` count, and they never equal each other to trigger a length update. 
3. **The Bidirectional Solution:** To cover the blindspot, we can do a second pass from right to left. During the right-to-left traversal, an excess of opening brackets acts exactly like an excess of closing brackets did in the first pass—it invalidates the current sequence, allowing us to safely reset our counters and find the true maximum length.

---

## 🧠 Approach

### Approach 1: Two-Pass Counter (O(1) Space)
We can solve this without any extra space by utilizing two counters: `open` and `close`. 
1. **Left-to-Right Pass:** Iterate through the string. Increment the `open` counter for `'('` and the `close` counter for `')'`. 
   - If `open == close`, we have a valid balanced substring, so we update our maximum length. 
   - If `close > open`, the string is permanently invalid going forward from that index, so we reset both counters to 0.
2. **Right-to-Left Pass:** To catch edge cases with excess opening brackets, reset the counters and traverse the string backwards. 
   - Increment counters normally, update max length when they match.
   - This time, if `open > close`, it signifies an invalid state, so we reset both counters to 0.

### Approach 2: Stack-Based (O(N) Space)
1. Initialize a stack and push `-1` onto it. This `-1` acts as a base index for the very first valid substring.
2. Iterate through the string. If the character is `'('`, push its index onto the stack.
3. If the character is `')'`, pop the top element from the stack.
4. If the stack becomes empty after popping, it means this `')'` is unbalanced. We push its current index onto the stack to serve as the new base index for future valid substrings.
5. If the stack is not empty after popping, we calculate the length of the current valid substring by subtracting the index at the top of the stack from the current index `i`, and update the maximum length accordingly.

## 💻 Solution Code

### Optimized Solution 1: Two Pass (Left-Right & Right-Left)

```cpp
// Intuition: Counting brackets iteratively catches balanced sequences without extra memory. A left-to-right pass handles excess closing brackets, and a right-to-left pass handles excess opening brackets.
// Approach: Traverse the string twice (L->R then R->L). Track open/close counts. Update max length when they match. Reset counts when invalid (close > open for L->R, open > close for R->L).
// Time Complexity: O(n), where n is the length of the string. We traverse the string exactly twice.
// Space Complexity: O(1), as we only use a few variables (open, close, result) for tracking.

//Approach-1 (Using 2 pass)
//T.C : O(n), 2 Pass
//S.C : O(1)
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = s.length();

        int open  = 0;
        int close = 0;

        int result = 0;

        // First pass: Left to Right
        for(int i = 0; i < n; i++) {
            // Count respective brackets
            if(s[i] == '(') open++;
            else close++;

            // Balanced state achieved
            if(open == close) {
                result = max(result, open+close);
            } else if(close > open) { //going from left to right, if close is more, it's no more valid
                open  = 0;
                close = 0;
            }
        }

        // Reset variables for second pass
        open  = 0;
        close = 0;
        
        // Second pass: Right to Left
        for(int i = n-1; i >= 0; i--) {
            // Count respective brackets
            if(s[i] == '(') open++;
            else close++;

            // Balanced state achieved
            if(open == close) {
                result = max(result, open+close);
            } else if(open > close) { //going from right to left, if open is more, it's no more valid
                open  = 0;
                close = 0;
            }
        }

        return result;
    }
};

/*
*
* Dry Run
* String s = "(()"
* L->R Pass:
* i=0, '(': open=1, close=0
* i=1, '(': open=2, close=0
* i=2, ')': open=2, close=1. (Max stays 0)
* R->L Pass:
* i=2, ')': close=1, open=0
* i=1, '(': close=1, open=1 -> Equal! Result = max(0, 1+1) = 2.
* i=0, '(': close=1, open=2 -> open > close, reset open=0, close=0.
* Final Result = 2.
*
*/
```

### Optimized Solution 2: Stack Based

```cpp
// Intuition: A stack can efficiently track the indices of unbalanced brackets. The distance between the current matched bracket and the last unpopped boundary yields the length of the valid segment.
// Approach: Push an initial boundary (-1). For '(', push the index. For ')', pop. If the stack empties, push the current index as a new boundary. Otherwise, length is (current index - stack top).
// Time Complexity: O(n), as we iterate through the string characters exactly once. Stack operations take O(1).
// Space Complexity: O(n), in the worst case (e.g., all '('), we will push all indices onto the stack.

//Approach-2 (Using Stack)
//T.C : O(n) - 1 Pass
//S.C : O(n)
class Solution {
public:
    int longestValidParentheses(string s) {
        stack<int> st;
        // Base index for initial valid substring calculations
        st.push(-1);

        int maxL = 0;
        int n = s.length();

        for(int i = 0; i < n; i++) {
            if(s[i] == '(') {
                // Push index of open bracket
                st.push(i);
            } else {
                // Pop for the closing bracket
                st.pop();
                
                if(st.empty()) {
                    // Current closing bracket is invalid, becomes new baseline
                    st.push(i);
                } else {
                    // Valid match found, calculate length using current stack top
                    maxL = max(maxL, i-st.top());
                }
            }
        }
        return maxL;
    }
};

/*
*
* Dry Run
* String s = ")()())"
* Stack starts with [-1]. maxL = 0
* i=0, ')': pop -1. Stack empty -> push 0. Stack: [0]
* i=1, '(': push 1. Stack: [0, 1]
* i=2, ')': pop 1. Stack: [0]. maxL = max(0, 2-0) = 2
* i=3, '(': push 3. Stack: [0, 3]
* i=4, ')': pop 3. Stack: [0]. maxL = max(2, 4-0) = 4
* i=5, ')': pop 0. Stack empty -> push 5. Stack: [5]
* Final Result = 4.
*
*/
```

## 📌 Notes
- The two-pass method is highly favored in interviews because it reduces the space complexity to true `O(1)` while maintaining the `O(N)` time complexity.
- Understanding why the right-to-left traversal is necessary (to catch unclosed opening brackets) is the crux of mastering the O(1) space approach.

## 🚀 Further Exploration
- Explore how Dynamic Programming can be applied to this problem. An array `dp[i]` can be used to store the length of the longest valid substring ending at index `i`.
