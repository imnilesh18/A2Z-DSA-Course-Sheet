## 📝 Problem Statement

Given the root of a binary tree, return the number of nodes where the value of the node is equal to the **average** of the values in its subtree.

**Notes:**
* The average of `n` elements is the sum of the `n` elements divided by `n` and **rounded down** to the nearest integer.
* A subtree of `root` is a tree consisting of `root` and all of its descendants.

---

## ⚠️ Constraints

* The number of nodes in the tree is in the range `[1, 1000]`.
* `0 <= Node.val <= 1000`

## 🧠 Approach

<details>
<summary><b>1️⃣ Brute Force (O(N²))</b></summary>
<br>
In a brute force approach, we visit every node in the tree. For each node, we perform a complete Depth First Search (DFS) on its subtree to calculate the sum of all node values and the total count of nodes. Then we check if <code>sum / count == node.val</code>. 

Because we are doing a nested traversal (visiting the subtree for *every* node), this approach forces us to repeatedly calculate the sum and count for nodes we've already visited. This leads to a time complexity of `O(N²)`.
</details>

<details open>
<summary><b>2️⃣ Optimized Post-order Traversal (O(N))</b></summary>
<br>
To avoid redundant calculations, we can process the tree from the **bottom up** using a Post-order Traversal (Left, Right, Root). 

Instead of searching downwards, each node will gather information from its children and pass it upwards to its parent. 
1. We recursively call the function on the left and right children.
2. Each recursive call returns a pair of values: `{sum_of_subtree, count_of_nodes}`.
3. For the current node, we calculate its total subtree sum: `left_sum + right_sum + current_node.val`.
4. We calculate its total node count: `left_count + right_count + 1`.
5. We check if the average `(total sum / total count)` equals the current node's value.
6. Finally, we return the newly calculated `{sum, count}` pair up to the parent node.

By returning this state upwards, we visit each node exactly once, achieving an optimal `O(N)` time complexity.
</details>

## 💻 Solution Code

### Brute Force Solution
```cpp
// Intuition: The most straightforward way is to visit every node and calculate the sum and number of nodes in its subtree. If the average matches the node's value, we count it.
// Approach: 
// 1. Traverse the tree using DFS.
// 2. For each node, calculate the total sum and total count of its subtree using a helper function sum().
// 3. Check if totalSum / count equals the current node's value. If yes, increment the result.
// 4. Recursively repeat this for left and right children.
// Time Complexity: O(n^2), where n is the number of nodes. For each of the n nodes, we potentially visit all its descendants to calculate the sum.
// Space Complexity: O(n) in the worst case (skewed tree) for the recursion stack space, O(log n) for a balanced tree.
class Solution {
public:
    int result;
    
    // Helper function to calculate sum and count of nodes in a subtree
    int sum(TreeNode* root, int &count) {
        if(!root)
            return 0;
        
        count++; // Increment count for the current node
        
        // Recursively get sum of left and right subtrees
        int l = sum(root->left, count);
        int r = sum(root->right, count);
        
        return l + r + root->val; // Return total sum of the subtree
    }
    
    void solve(TreeNode* root) {
        if(!root)
            return;
        
        int count = 0;
        int totalSum = sum(root, count); // Calculate sum and count for current subtree
        
        // Check if average equals node's value
        if((totalSum)/count == root->val) {
            result++;
        }
        
        // Recursively check left and right children
        solve(root->left);
        solve(root->right);
    }
    
    int averageOfSubtree(TreeNode* root) {
        result = 0;
        
        solve(root); // Start DFS from root
        
        return result;
    }
};

/*
*
* Dry Run
* Let's trace root = [1]
* 1. averageOfSubtree(1) is called. result = 0. solve(1) is called.
* 2. solve(1): count = 0. sum(1, count) is called.
* 3. sum(1, count): root is not null. count becomes 1. l = sum(null, count) = 0. r = sum(null, count) = 0. returns 0 + 0 + 1 = 1.
* 4. Back to solve(1): totalSum = 1, count = 1. avg = 1/1 = 1. Equals root->val (1). result becomes 1.
* 5. solve(1->left) -> solve(null) returns. solve(1->right) -> solve(null) returns.
* 6. End of solve. Return result = 1.
*
*/
```

### Optimized Solution
```cpp
// Intuition: Instead of recalculating the sum and count for every subtree from top to bottom, we can calculate them from bottom to top using Postorder Traversal, passing the computed values up the tree to avoid redundant work.
// Approach: 
// 1. Perform a Postorder Traversal (Left, Right, Root).
// 2. Each recursive call returns a pair: {sum_of_subtree, count_of_nodes_in_subtree}.
// 3. For a given node, its subtree sum is left_sum + right_sum + node.val, and its count is left_count + right_count + 1.
// 4. Calculate the average. If it matches the node's value, increment the result.
// 5. Return the new {sum, count} pair to the parent node.
// Time Complexity: O(n) because we visit each node exactly once.
// Space Complexity: O(n) in the worst case (skewed tree) for the recursion stack space, O(log n) for a balanced tree.
class Solution {
public:
    int result;
    
    // Returns a pair of {sum, count} for the subtree
    pair<int, int> solve(TreeNode* root) {
        if(!root)
            return {0, 0}; // Base case: empty node contributes 0 to sum and 0 to count
        
        // Process left and right subtrees first (Postorder)
        pair<int, int> l = solve(root->left);
        pair<int, int> r = solve(root->right);
        
        // Extract values from left subtree
        int leftSum   = l.first;
        int leftCount = l.second;
        
        // Extract values from right subtree
        int rightSum   = r.first;
        int rightCount = r.second;
        
        // Calculate total sum and count for the current node's subtree
        int SUM   = leftSum + rightSum + root->val;
        int COUNT = leftCount + rightCount + 1;
        
        // Calculate average (rounded down by integer division)
        int avg = SUM/COUNT;
        
        // Check condition and increment result if matched
        if(avg == root->val) {
            result++;
        }
        
        // Return accumulated values to the parent
        return {SUM, COUNT};
    }
    
    int averageOfSubtree(TreeNode* root) {
        result = 0;
        
        solve(root); // Start postorder traversal
        
        return result;
    }
};

/*
*
* Dry Run
* Let's trace root = [4,8,5,0,1,null,6]
* 1. Postorder goes deep left. Leaf '0' returns {0,1}.
* 2. Leaf '1' returns {1,1}.
* 3. Node '8': gets {0,1} from left, {1,1} from right. SUM = 0+1+8 = 9. COUNT = 1+1+1 = 3. avg = 9/3 = 3 (not 8). Returns {9,3}.
* 4. Node '6' (right of 5) returns {6,1}.
* 5. Node '5': gets {0,0} from left, {6,1} from right. SUM = 0+6+5 = 11. COUNT = 0+1+1 = 2. avg = 11/2 = 5 (equals 5!). result = 1. Returns {11,2}.
* 6. Node '4' (root): gets {9,3} from left, {11,2} from right. SUM = 9+11+4 = 24. COUNT = 3+2+1 = 6. avg = 24/6 = 4 (equals 4!). result = 2. Returns {24,6}.
* 7. Final result includes all matching subtrees (leaves 0, 1, 6 also match). Total result = 5.
*
*/
```

## 📌 Key Insights & Notes
* **Integer Division:** C++ naturally floors positive integer division. Simply doing `SUM / COUNT` will give us the mathematically "rounded down" quotient as requested by the problem.
* **Bottom-Up State Passing:** Any time a tree problem requires querying an entire subtree to make a decision at the parent node, consider a **Post-Order Traversal** where you pass state `(like sum, depth, or count)` up to the parent. This turns an `O(N²)` problem into `O(N)`.
* **Leaf Nodes Trick:** By definition, all leaf nodes will automatically count toward the answer because `node.val / 1 == node.val`.
