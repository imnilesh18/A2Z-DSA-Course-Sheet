## 📝 Problem Statement

You are given two integers `m` and `n`, representing the number of rows and columns of a grid.

Construct any `m x n` grid consisting only of the characters `'.'` and `'#'`, where:
- `'.'` represents a free cell.
- `'#'` represents an obstacle cell.

A valid path is a sequence of free cells that:
- Starts at the top-left cell `(0, 0)`.
- Ends at the bottom-right cell `(m - 1, n - 1)`.
- Moves only:
  - Right, from `(i, j)` to `(i, j + 1)`, or
  - Down, from `(i, j)` to `(i + 1, j)`.

Return any grid such that there is **exactly one** valid path from the top-left cell to the bottom-right cell.

## ⚙️ Constraints

- `1 <= m, n <= 25`

To ensure there is exactly *one* valid path from the top-left to the bottom-right corner, we can construct a strict, unobstructed corridor while placing obstacles everywhere else. 

The most straightforward way to guarantee a single path is to create an "L" shaped corridor. By making the entire first row free of obstacles, we force the path to move all the way to the right side of the grid. By placing obstacles on all subsequent rows—except for the very last column—we force the path to drop straight down along the right edge. Since diagonal moves are not allowed and moving left/up is impossible, this strict right-then-down structure guarantees a unique path.

## 💻 Solution Code

### Optimized Solution (C++)

```cpp
// Intuition: To guarantee exactly one valid path, we can create a single 'L' shaped corridor. The simplest way is to clear the top row and the rightmost column, filling the rest with obstacles.
// Approach: 
// 1. Create the first row entirely of free cells ('.').
// 2. Create a template string for remaining rows: n-1 obstacles ('#') followed by 1 free cell ('.').
// 3. Add the top row to the result vector.
// 4. Iterate from row 1 to m-1, pushing the remaining row template.
// 5. Return the constructed grid.
// Time Complexity: O(m * n) because we process strings of length n across m rows.
// Space Complexity: O(n) auxiliary space to store the 'topRow' and 'remaining' strings.
class Solution {
public:
    vector<string> createGrid(int m, int n) {
        // Construct the top row with all free cells
        string topRow(n, '.');
        
        // Construct remaining rows: n-1 obstacles followed by 1 free cell
        string remaining = string(n - 1, '#') + '.';

        vector<string> result;
        
        // Add the top row to our grid
        result.push_back(topRow);

        // Add the structured rows to complete the grid
        for(int i = 1; i < m; i++) {
            result.push_back(remaining);
        }

        return result;
    }
};

/*
*
* Dry Run
* m = 3, n = 3
* topRow = "..." (3 dots)
* remaining = "##." (2 hashes + 1 dot)
* result initialized empty
* Add topRow -> result = ["..."]
* i = 1: Add remaining -> result = ["...", "##."]
* i = 2: Add remaining -> result = ["...", "##.", "##."]
* Final Grid returned. 
* Valid Path taken: (0,0) -> (0,1) -> (0,2) -> (1,2) -> (2,2). Exactly 1 path exists.
*
*/
```

## 📝 Notes & Key Insights

- **Constructive Algorithm:** This problem doesn't require complex path-finding algorithms like BFS or DFS. It tests your ability to identify and build a guaranteed valid structure.
- **String Constructor:** Utilizing C++'s `string(size_t n, char c)` constructor keeps the code highly readable and avoids unnecessary manual inner loops.

## 🚀 Further Exploration

- **Alternative Corridor:** An equally valid $O(m \times n)$ solution is the inverted L-shape: make the entire first column free (`'.'`), then make the entire last row free (`'.'`), placing obstacles everywhere else.
