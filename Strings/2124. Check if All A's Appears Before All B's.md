## 📋 Problem Statement

Given a string `s` consisting of **only** the characters `'a'` and `'b'`, return `true` if **every** `'a'` appears before **every** `'b'` in the string. Otherwise, return `false`.

🔗 **Problem Link:** [2124. Check if All A's Appears Before All B's](https://leetcode.com/problems/check-if-all-as-appears-before-all-bs/description)

---

## 🔒 Constraints

* $1 \le \text{s.length} \le 100$
* `s[i]` is either `'a'` or `'b'`.

---

## 🧪 Examples

| Example | Input | Output | Explanation |
| :---: | :--- | :---: | :--- |
| **1** | `s = "aaabbb"` | `true` | The `'a'`s are at indices `0, 1, 2`, while the `'b'`s are at indices `3, 4, 5`. Every `'a'` appears before every `'b'`, so we return `true`. |
| **2** | `s = "abab"` | `false` | There is an `'a'` at index `2` and a `'b'` at index `1`. Since an `'a'` appears after a `'b'`, not every `'a'` precedes every `'b'`, so we return `false`. |
| **3** | `s = "bbb"` | `true` | There are no `'a'`s in the string. Hence, no `'a'` ever appears after a `'b'`, and we return `true`. |
| **4 (Edge Case)** | `s = "aaa"` | `true` | There are no `'b'`s in the string. Since no `'b'` ever precedes an `'a'`, the condition holds and we return `true`. |

---

## 💡 Approach

Because the string contains exclusively `'a'` and `'b'`, the condition *"every `'a'` appears before every `'b'`"* can be viewed from five distinct, intuitive perspectives:

### 1️⃣ Approach 1: Adjacent Pair Check (Detecting `"ba"`)
* If every `'a'` must precede every `'b'`, there can **never** be a `'b'` immediately followed by an `'a'` anywhere in the string.
* Traverse the string starting from index `i = 1` up to `n - 1`.
* At each step, compare the previous character `s[i - 1]` with the current character `s[i]`.
* If `s[i - 1] == 'b'` and `s[i] == 'a'`, an `'a'` has appeared after a `'b'`, so immediately return `false`.
* If the entire string is scanned without encountering `"ba"`, return `true`.

### 2️⃣ Approach 2: Tracking Last `'a'` and First `'b'` Indices
* For all `'a'`s to appear before all `'b'`s, the **rightmost (last) occurrence of `'a'`** must appear at a strictly smaller index than the **leftmost (first) occurrence of `'b'`**.
* Initialize two index trackers: `last_a = -1` and `first_b = -1`.
* Iterate through the string from `0` to `n - 1`:
  * Every time `s[i] == 'a'`, update `last_a = i` so that it holds the final index of `'a'`.
  * Every time `s[i] == 'b'`, update `first_b = i` **only if** `first_b == -1` (preserving the very first `'b'` encountered).
* **Boundary Edge Cases:** If the string contains only `'b'`s (`last_a == -1`) or only `'a'`s (`first_b == -1`), no violation is possible, so return `true`.
* Otherwise, return `last_a < first_b`.

### 3️⃣ Approach 3: Substring Search for `"ba"`
* Building directly on Approach 1, a string violates the rule if and only if `"ba"` exists as a contiguous substring inside `s`.
* Use C++'s built-in `s.find("ba")` and check if it equals `string::npos`.
* **Complexity Nuance:** Searching for a pattern of length $M$ inside a text of length $N$ generally takes $O(N \times M)$ time (or $O(N + M)$ using the **KMP algorithm**). However, since the pattern `"ba"` has a fixed constant length $M = 2$, $O(N \times 2)$ simplifies directly to linear $O(N)$ time.

### 4️⃣ Approach 4: Sorted String Verification
* In ASCII ordering, `'a' < 'b'`.
* Having all `'a'`s appear before all `'b'`s in a binary-character string is mathematically identical to saying the string is **sorted in non-decreasing (ascending) order**.
* Using C++ STL's `is_sorted(begin(s), end(s))` checks whether every character is greater than or equal to its predecessor (`s[i] >= s[i - 1]`).
* The moment a smaller character (`'a'`) follows a larger character (`'b'`), `is_sorted` terminates early and returns `false`.

### 5️⃣ Approach 5: Counting `'a'`s and Verifying Prefix
* Suppose the total frequency of `'a'` in the string is `count_a`.
* For the string to be valid, **all** `count_a` occurrences of `'a'` must occupy the first `count_a` positions of the string (indices `0` through `count_a - 1`).
* First, count the total number of `'a'`s using `count(begin(s), end(s), 'a')`.
* Next, iterate `i` from `0` to `count_a - 1`. If any character `s[i] != 'a'`, an `'a'` must have been pushed past a `'b'`, so return `false`.
* If all first `count_a` characters are `'a'`, return `true`.

## 💻 Solution Code

### Brute Force / Direct Iterative Approaches

#### Approach 1: Adjacent Pair Check (Look for `"ba"`)

```cpp
// Intuition: Every 'a' appears before every 'b' if and only if no 'b' is immediately followed by an 'a'.
// Approach: Iterate from index 1 to n - 1 and check if s[i - 1] == 'b' and s[i] == 'a'. If found, return false; otherwise return true.
// Time Complexity: O(n), where n is the length of the string, as we perform a single linear scan.
// Space Complexity: O(1), as only a constant amount of extra space is used.
class Solution {
public:
    bool checkString(string s) {
        int n = s.length(); // Get length of input string

        for (int i = 1; i < n; i++) {
            // Check if an 'a' immediately follows a 'b'
            if (s[i - 1] == 'b' && s[i] == 'a') 
                return false;
        }
        return true; // No "ba" violation found
    }
};

/*
*
* Dry Run
*
* Input: s = "abab"
* n = 4
* i = 1: s[0] = 'a', s[1] = 'b' -> condition false
* i = 2: s[1] = 'b', s[2] = 'a' -> condition true, returns false
* Output: false
*
*/
```

---

#### Approach 2: Track Last `'a'` and First `'b'` Indices

```cpp
// Intuition: All 'a's precede all 'b's if the rightmost occurrence of 'a' appears at an index strictly before the leftmost occurrence of 'b'.
// Approach: Traverse the string once to record the last index of 'a' and the first index of 'b'. Handle single-character strings, then check last_a < first_b.
// Time Complexity: O(n), where n is the length of the string, due to a single pass through all characters.
// Space Complexity: O(1), as we only store two integer index variables.
class Solution {
public:
    bool checkString(string s) {
        int n = s.length(); // Get length of input string

        int first_b = -1; // Stores index of the first 'b'
        int last_a  = -1; // Stores index of the last 'a'

        for(int i = 0; i < n; i++) {
            if(s[i] == 'a') {
                last_a = i; // Continuously update to keep the rightmost 'a'
            } else if(first_b == -1) {
                first_b = i; // Record only the very first 'b' encountered
            }
        }

        // If string has only 'a's or only 'b's, no violation can occur
        if(first_b == -1 || last_a == -1)
            return true;
        
        return last_a < first_b; // Last 'a' must appear before first 'b'
    }
};

/*
*
* Dry Run
*
* Input: s = "aaabbb"
* n = 6, first_b = -1, last_a = -1
* i = 0 ('a'): last_a = 0
* i = 1 ('a'): last_a = 1
* i = 2 ('a'): last_a = 2
* i = 3 ('b'): first_b = 3
* i = 4 ('b'): first_b remains 3
* i = 5 ('b'): first_b remains 3
* Check: first_b != -1 and last_a != -1
* Return: last_a < first_b -> 2 < 3 -> true
* Output: true
*
*/
```

### Optimized / Idiomatic C++ Approaches

#### Approach 3: Substring Search for `"ba"`

```cpp
// Intuition: A string of 'a's and 'b's is invalid if and only if it contains the contiguous substring "ba".
// Approach: Use std::string::find to search for "ba" and verify that it returns string::npos.
// Time Complexity: O(n), since searching a pattern of constant length M = 2 in a string of length n takes O(n * 2) = O(n) time.
// Space Complexity: O(1), using no auxiliary data structures.
class Solution {
public:
    bool checkString(string s) {
        // Return true if "ba" is not found anywhere in s
        return s.find("ba") == string::npos;
    }
};

/*
*
* Dry Run
*
* Input: s = "bbb"
* s.find("ba") searches for "ba" in "bbb" -> not found, returns string::npos
* Comparison: string::npos == string::npos -> true
* Output: true
*
*/
```

#### Approach 4: Check if String is Sorted

```cpp
// Intuition: Since 'a' < 'b' in ASCII, having all 'a's appear before all 'b's means the string is sorted in non-decreasing order.
// Approach: Use C++ STL's is_sorted() to verify that no character is smaller than its preceding character.
// Time Complexity: O(n), as is_sorted performs a single linear comparison across adjacent characters.
// Space Complexity: O(1), requiring constant extra memory.
class Solution {
public:
    bool checkString(string s) {
        // Verify characters are in ascending order ('a's followed by 'b's)
        return is_sorted(begin(s), end(s));
    }
};

/*
*
* Dry Run
*
* Input: s = "aabab"
* Checks s[0] <= s[1] ('a' <= 'a') -> ok
* Checks s[1] <= s[2] ('a' <= 'b') -> ok
* Checks s[2] <= s[3] ('b' <= 'a') -> false, stops immediately
* Output: false
*
*/
```

---

#### Approach 5: Count `'a'`s and Verify Prefix

```cpp
// Intuition: If there are count_a occurrences of 'a' in total, all of them must occupy the first count_a positions of the string.
// Approach: Count the total number of 'a's in s, then verify that every index from 0 to count_a - 1 contains 'a'.
// Time Complexity: O(n), requiring one pass to count 'a's and at most one pass to verify the prefix.
// Space Complexity: O(1), using only a single counter variable.
class Solution {
public:
    bool checkString(string s) {
        int count_a = count(begin(s), end(s), 'a'); // Count total occurrences of 'a'
        
        // the first count_a characters must all be 'a' for all 'a's to precede 'b's
        for (int i = 0; i < count_a; i++) {
            if (s[i] != 'a') 
                return false; // Found a 'b' within the expected 'a'-prefix
        }

        return true; // All 'a's are packed at the start of the string
    }
};

/*
*
* Dry Run
*
* Input: s = "aabba"
* count_a = 3
* i = 0: s[0] == 'a' -> ok
* i = 1: s[1] == 'a' -> ok
* i = 2: s[2] == 'b' != 'a' -> returns false
* Output: false
*
*/
```

## 📝 Notes

* **Early Exit Advantage:** Approaches 1, 3, and 4 terminate immediately as soon as the first `'b'` followed by `'a'` is encountered, making them optimal in practice for strings with early violations.
* **Single-Character Strings:** Strings containing only `'a'`s (e.g., `"aaaa"`) or only `'b'`s (e.g., `"bbb"`) are always valid and must return `true` because the universal condition *"every `'a'` appears before every `'b'`"* is vacuously satisfied.
* **Why `s.find("ba")` is Linear:** Even though general substring matching takes $O(N \times M)$ time (or $O(N + M)$ with KMP), here $M = 2$ is strictly fixed, guaranteeing $O(N)$ runtime without needing KMP overhead.

---

## 🔑 Key Insights

1. **Global Property vs. Local Invariant:** A global ordering constraint (*"all `'a'`s before all `'b'`s"*) reduces cleanly to a local forbidden pattern (`"ba"`) because the alphabet has size 2.
2. **Lexicographical Equivalence:** Over a binary alphabet `{'a', 'b'}`, partitioning all `'a'`s to the left and all `'b'`s to the right is identical to sorting the string.
3. **Prefix Packing:** Counting total `'a'`s converts the ordering check into a simple prefix membership verification (`s[0 ... count_a - 1] == 'a'`).
